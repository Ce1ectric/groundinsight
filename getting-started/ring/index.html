    From a line to a ring¶

    Distribution networks are rarely a single line. In a ring the fault current has two routes to the fault, and how it divides between them decides how much current each cable shield is driven with. This tutorial lays the cable of Your first fault calculation as a ring, shows how groundinsight divides the current, adds a harmonic, and checks the numbers by hand again.

    What you will build¶

    Four stations on a ring of four 2.5 km sections of the same cable. The infeed sits at bus_source, the fault at bus_fault on the opposite side; each of the two routes is 5 km long, like the line of the first tutorial:

                    cable_1, 2.5 km         cable_2, 2.5 km
   bus_source ================= bus_a ================= bus_fault
       ||                                                  ||
       ||       cable_3, 2.5 km         cable_4, 2.5 km    ||
       ++====================== bus_b =====================++

    Every station has the electrode of the first tutorial, \(Z_B = 1 + 0.1j\ \Omega\) at 50 Hz.

    Step 1 — Build the ring¶

    The construction goes into a function, because the ring is built again in later steps:

    import groundinsight as gi


def build_ring(frequencies, source_values, phase_impedance_formula=None):
    """The ring of the tutorial, ready to solve."""
    net = gi.create_network(name="ring", frequencies=frequencies)
    station = gi.BusType(
        name="SubstationBus", system_type="Substation", voltage_level=20.0,
        impedance_formula="rho * 0.01 + j * f * 1/50 * 0.1",
    )
    cable = gi.BranchType(
        name="MSCable", grounding_conductor=True,
        self_impedance_formula="(0.25 + j * f * 0.012) * l",
        mutual_impedance_formula="(0.0 + j * f * 0.012) * l",
        phase_impedance_formula=phase_impedance_formula,
    )
    for bus in ("bus_source", "bus_a", "bus_fault", "bus_b"):
        gi.create_bus(name=bus, type=station, specific_earth_resistance=100.0,
                      network=net)
    for name, a, b in (("cable_1", "bus_source", "bus_a"),     # route 1
                       ("cable_2", "bus_a", "bus_fault"),
                       ("cable_3", "bus_source", "bus_b"),     # route 2
                       ("cable_4", "bus_b", "bus_fault")):
        gi.create_branch(name=name, type=cable, from_bus=a, to_bus=b,
                         length=2.5, network=net)
    gi.create_source(name="substation_infeed", bus="bus_source",
                     values=source_values, network=net)
    gi.create_fault(name="fault_at_remote_bus", bus="bus_fault", network=net)
    return net

    Step 2 — Solve: the current divides¶

    net = build_ring([50.0], {50.0: 1000.0})
with warnings.catch_warnings(record=True) as caught:
    warnings.simplefilter("always")
    result = gi.run_fault(net, fault="fault_at_remote_bus")
for warning in caught:
    print(warning.category.__name__, warning.message.code)
print([d.code for d in result.diagnostics])

    ModelAssumptionWarning PHASE_PROXY
['PHASE_PROXY']

    In a line every branch between infeed and fault carries the full fault current. In a ring the current divides, and groundinsight finds the split by solving a second network made of the phase conductors alone, with the fault as reference. That network needs the impedance of each phase conductor, which the type does not declare yet. The solver therefore falls back to a proxy — the shield impedance — and says so with a ModelAssumptionWarning, code PHASE_PROXY. Here the proxy happens to be harmless: both routes are the same cable over the same length, so any impedance proportional to length divides the current 500 A : 500 A. In a ring that mixes a cable with an overhead line the proxy is a guess (Phase currents in rings and meshes).

    Step 3 — Declare the phase impedance¶

    What the split needs is the loop of the faulted phase conductor with earth return, with the shield bonded at both ends: \(Z_\text{red} = Z_{pp} - Z_m^2/Z_s\), where \(Z_{pp}\) is the phase–earth loop on its own. With an illustrative \(Z_{pp} = 0.15 + j\,f\,0.015\ \Omega\)/km the formula reads:

    Z_RED = "((0.15 + j*f*0.015) - (j*f*0.012)**2 / (0.25 + j*f*0.012)) * l"

net = build_ring([50.0], {50.0: 1000.0}, phase_impedance_formula=Z_RED)
result = gi.run_fault(net, fault="fault_at_remote_bus")
print([d.code for d in result.diagnostics])

key = net.res_fault("fault_at_remote_bus").row(0, named=True)  # the 50 Hz row
print(f"U_E  = {key['U_E_V']:.2f} V")
print(f"Z_E  = {key['Z_E_Ohm']:.4f} Ohm at {key['Z_E_degree']:.2f} deg")
print(f"I_E  = {key['I_E_A']:.2f} A")
print(f"r    = {key['r_current']:.6f}   EPR ratio = {key['r_epr']:.6f}")

    []
U_E  = 200.84 V
Z_E  = 0.5631 Ohm at 27.11 deg
I_E  = 199.85 A
r    = 0.199847   EPR ratio = 0.384615

    The warning is gone, and the numbers are those of Step 2: the symmetric split does not depend on the impedance value. Bus and branch types from data sheets computes \(Z_\text{red}\) for a real cable.

    Step 4 — Where the current goes¶

    buses = net.res_buses(fault="fault_at_remote_bus")
for row in buses.filter(buses["frequency_Hz"] == 50.0).iter_rows(named=True):
    print(f"{row['bus_name']:<11} EPR {row['EPR_V']:8.2f} V   electrode {row['I_bus_A']:8.2f} A")

    bus_source  EPR   200.84 V   electrode   199.85 A
bus_a       EPR     0.00 V   electrode     0.00 A
bus_fault   EPR   200.84 V   electrode   199.85 A
bus_b       EPR     0.00 V   electrode     0.00 A

    The two stations half way along the routes stay at zero potential and carry no current: the ring is symmetric about them, and the earth current enters the soil at the fault and leaves it at the infeed only.

    Step 5 — Check it by hand¶

    The symmetry gives the closed forms. Each route carries \(I/2\); because the ratio \(k = Z_m/Z_s\) is the same on every section, the coupling of the phase current shows up as a current \((1-k)\,I\) that enters the earthing network at the infeed and leaves it at the fault. With bus_a and bus_b at zero potential, the earthing network seen from the fault is its own electrode in parallel with the two half-routes, \(Z_s/2\) for one section of 2.5 km (\(Z_s = 0.625 + 1.5j\ \Omega\), \(Z_m = 1.5j\ \Omega\)):

    \[ \lvert U_E\rvert = \lvert 1-k\rvert\, I\, \bigl\lvert Z_B \parallel \tfrac{Z_s}{2} \bigr\rvert, \qquad r = \frac{\lvert I_E\rvert}{I} = \frac{\lvert Z_s - Z_m\rvert/2}{\lvert Z_B + Z_s/2\rvert}, \qquad Z_E = Z_B \parallel \Bigl(\tfrac{Z_s}{2} + \tfrac{Z_B}{2} \parallel \bigl(\tfrac{Z_s}{2} + Z_B\bigr)\Bigr). \]

    The last one is one ampere injected at bus_fault: its own electrode in parallel with the two half-routes to the electrodes of bus_a and bus_b (in parallel by symmetry, \(Z_B/2\)), and from there the other two half-routes to the electrode of bus_source.

    z_b = 1.0 + 0.1j                 # electrode, rho = 100 Ohm m, 50 Hz
z_s = (0.25 + 0.6j) * 2.5        # shield-earth loop of one 2.5 km section
z_m = 0.6j * 2.5                 # coupling of one section
current = 1000.0


def parallel(a, b):
    """The parallel connection of two impedances."""
    return a * b / (a + b)


# By symmetry each route carries current / 2, and bus_a and bus_b stay at
# zero potential: the earthing network is bus_source and bus_fault joined
# by the two half-routes in parallel (z_s / 2 each), with a Norton current
# (1 - k) * current between them.
k = z_m / z_s
u_e = abs(1 - k) * current * abs(parallel(z_b, z_s / 2))
r = abs(z_s / 2 - z_m / 2) / abs(z_b + z_s / 2)
z_e = parallel(z_b, z_s / 2 + parallel(z_b / 2, z_s / 2 + z_b))
print(f"by hand: U_E = {u_e:.2f} V, r = {r:.6f}, EPR ratio = {abs(1 - k):.6f}, "
      f"Z_E = {abs(z_e):.4f} Ohm at {cmath.phase(z_e) * 180 / cmath.pi:.2f} deg")

    by hand: U_E = 200.84 V, r = 0.199847, EPR ratio = 0.384615, Z_E = 0.5631 Ohm at 27.11 deg

    Compared with the line of the first tutorial, the second route halves the shield impedance between infeed and fault, so more of the return current takes the shields: r falls from 0.274064 to 0.199847, \(U_E\) from 275.43 V to 200.84 V, and \(Z_E\) from 0.8440 Ω to 0.5631 Ω. The EPR ratio stays at 0.384615 — with the same \(k\) on every branch it is \(|1-k|\) in any topology.

    Step 6 — Why dividing the current matters¶

    Older versions of groundinsight gave every route the full source current. That mode is still available, so that old studies can be reproduced:

    legacy = build_ring([50.0], {50.0: 1000.0}, phase_impedance_formula=Z_RED)
with warnings.catch_warnings():
    warnings.simplefilter("ignore", gi.ModelAssumptionWarning)
    gi.run_fault(legacy, fault="fault_at_remote_bus", phase_current_mode="paths")
old = legacy.res_fault("fault_at_remote_bus").row(0, named=True)
print(f"paths mode: U_E = {old['U_E_V']:.2f} V, EPR ratio = {old['r_epr']:.6f}")

    paths mode: U_E = 522.19 V, EPR ratio = 1.000000

    With 1000 A on both routes the coupling is counted twice, and the earthing network sees \((1-2k)\,I\) instead of \((1-k)\,I\). For this cable \(|1-2k| = |0.625 - 1.5j| / |0.625 + 1.5j| = 1\): the EPR comes out as if the shields did not couple at all, 2.6 times too high. With other cables the same mistake can drive the result towards zero instead. The default, phase_current_mode="auto", divides the current and needs nothing from you (Phase currents in rings and meshes).

    Step 7 — Add a harmonic¶

    A fault current is rarely a pure 50 Hz sine. Add the frequencies to the network and give the source an RMS value for each; the fault scales every frequency with 1.0 unless scalings says otherwise:

    net = build_ring([50.0, 250.0], {50.0: 1000.0, 250.0: 200.0},
                 phase_impedance_formula=Z_RED)
gi.run_fault(net, fault="fault_at_remote_bus")
for row in net.res_fault("fault_at_remote_bus").iter_rows(named=True):
    label = "RMS" if row["is_rms"] else f"{row['frequency_Hz']:.0f} Hz"
    ratios = ("" if row["is_rms"] else
              f"   r = {row['r_current']:.6f}   EPR ratio = {row['r_epr']:.6f}")
    print(f"{label:>6}: I_F = {row['I_F_A']:7.2f} A   U_E = {row['U_E_V']:7.2f} V{ratios}")

     50 Hz: I_F = 1000.00 A   U_E =  200.84 V   r = 0.199847   EPR ratio = 0.384615
250 Hz: I_F =  200.00 A   U_E =   15.71 V   r = 0.070255   EPR ratio = 0.083045
   RMS: I_F = 1019.80 A   U_E =  201.46 V

    Every frequency is an independent solve; the 50 Hz row is that of Step 3. At 250 Hz the shield reactance dominates its resistance, the shield takes nearly all of the return current, and the EPR ratio falls to \(0.25/\lvert 0.25 + 3j\rvert = 0.083045\). The RMS row combines the frequencies, \(\sqrt{200.84^2 + 15.71^2}\) = 201.46 V; it has no reduction factors, because a ratio of RMS values is not a property of the network.

    Step 8 — Which reduction factor to read¶

    Column Field Meaning Use it for
    r_current (res_fault), reduction_factor_current (res_all_impedances) value_current share of the fault current that returns through the soil, \(\lvert I_E\rvert/\lvert 3I_0\rvert\) the reduction factor r of EN 50522; sensitivity to electrodes and soil
    r_epr (res_fault), reduction_factor (res_all_impedances) value EPR at the fault with coupling over EPR without comparing cables: for a homogeneous run it is the tabulated \(\lvert 1 - Z_m/Z_s\rvert\), and it does not respond to the electrodes

    For a check against the limits of the standard, compare \(U_E\) itself with the permissible value — Compare results with EN 50522 limits describes the procedure.
