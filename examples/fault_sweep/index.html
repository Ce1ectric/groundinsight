    Fault sweep — earthing impedance and reduction factors per bus¶

    When the fault location is not known a priori, a common analysis is to sweep the fault across every candidate bus and read off the earthing impedance $Z_E$ and the reduction factors at each fault site. This notebook demonstrates that workflow on a 10-bus MV cable line and visualises the results with Network.res_all_impedances().

    Steps:

    1. Build a 10-bus MV cable line at five frequencies (50, 250, 350, 450, 550 Hz).
    2. Create one fault per bus, plus a single source at bus01.
    3. Loop gi.run_fault over every fault.
    4. Read the long-format DataFrame returned by res_all_impedances().
    5. Plot $|Z_E|$ and both reduction factors per fault bus and frequency.

    import warnings

import numpy as np
import polars as pl
import matplotlib.pyplot as plt

import groundinsight as gi

    1. Bus and branch types¶

    Illustrative MV cable values: a shield-earth loop of $0.25 + j0.6\ \Omega$/km at 50 Hz whose reactance and the mutual reactance both grow with frequency. The cable has full mutual coupling ($\mathrm{Im}\,Z_\text{self} = \mathrm{Im}\,Z_\text{mutual}$), so its reduction factor at 50 Hz is $|1 - Z_\text{mutual}/Z_\text{self}| = 0.25/|0.25 + j0.6| = 0.384615$. Every station has an electrode of 1 Ω.

    2. Build a 10-bus line¶

    Source at bus01, one fault definition at every bus. Each fault re-uses the same source; run_fault solves one fault at a time.

    In [3]:

    FREQS = [50.0, 250.0, 350.0, 450.0, 550.0]

LINE_LENGTH_KM = 0.5  # km per section

    3. Run the sweep¶

    One gi.run_fault call per fault location. The fault at bus01 sits on the source bus itself: the source current enters and leaves the earthing system at the same bus, no current flows through the network, and both reduction factors are undefined there — res_all_impedances emits null for them. The earthing impedance is a property of the network at the fault bus and is defined there as well.

    Seven of the ten fault locations add EARTH_GROUP_SPREAD to their diagnostics: the electrode currents of the stations point in clearly different directions, so the earth current $I_E$ and the reduction factor on a current basis describe the dominant direction only (Reduction factor on a current basis).

    5. A second way to $Z_E$¶

    $Z_E$ is the driving-point impedance of the earthing network at the fault bus. gi.bus_response computes, from two solves, the impedance $Z_\text{net}$ that the rest of the network offers at a bus; in parallel with the bus's own electrode (1 Ω) it must give $Z_E$.

    Copied! 
    response = gi.bus_response(net, fault="f05", bus="bus05")
z_net = response.z_network[50.0]
z_e_second_way = 1.0 / (1.0 / 1.0 + 1.0 / z_net)
z_e_sweep = impedance_df.filter(
    (pl.col("fault_name") == "f05") & (pl.col("frequency_Hz") == 50.0)
)["grounding_impedance_Ohm"][0]
print(f"|Z_E| at bus05, 50 Hz: sweep {z_e_sweep:.6f} ohm, bus_response {abs(z_e_second_way):.6f} ohm")

    7. Profile interpretation¶

    • $|Z_E|$ is symmetric about the middle of the line. It is the impedance of the earthing network seen from the fault bus — all electrodes in parallel through the shields — and does not depend on where the source is. The two end stations have bonded neighbours on one side only and show the highest value; inside the line it is nearly constant.
    • The EPR ratio is the same at every fault location at a given frequency: every section is the same cable, so it is $|1 - Z_m/Z_s|$ of the cable, 0.384615 at 50 Hz. It falls with frequency, because the shield reactance grows while its resistance stays — to below 0.05 at 550 Hz.
    • The reduction factor of EN 50522 depends on the position. Close to the infeed the shield back to it is short and carries almost all of the return current; the farther away the fault, the longer that path and the more current takes the soil. At 50 Hz it grows from 0.079 at bus02 to 0.389 at bus10; at the harmonics, where the shield reactance dominates, it levels off after a few stations close to the EPR ratio of that frequency. It is the factor that responds to the electrodes and the position; the EPR ratio describes the cable.

    The wide DataFrames can be exported to CSV or Excel directly via polars.DataFrame.write_csv / write_excel for downstream reporting. Reduction factors and earthing impedance explains the two factors.
