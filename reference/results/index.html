    Result tables¶

    Every solve stores one Result per fault on the network, and the package hands results out as Polars data frames: the res_* accessors of Network, the study results, the thermal checks and the importers. This page lists every column of every frame with its type, unit and meaning.

    The column names and types in the tables below are generated from the code when this site is built — from the schema constants that pin the frames (RES_BUSES_SCHEMA, gi.RES_FAULT_SCHEMA, CUT_FRAME_SCHEMA, …) or, where a frame has no constant, from a frame built on a small network at build time. A test compares the constants with the frames of a real solve, so a table cannot describe a column the code no longer has.

    Rules that hold for every frame¶

    Units. Phasors are RMS values, currents in A, voltages in V, impedances in Ω, angles in degrees; the column name ends with the unit (_A, _V, _Ohm, _degree or _deg, _Hz, _s, _mm2). The time series of a transient study are instantaneous values. See Conventions and units.

    Signs. Magnitudes do not depend on a sign convention, angles do. Earth potentials, electrode currents and injections are reported in the earth-side frame (a current that enters the earthing network at the source and leaves it at the fault), branch currents for the physical fault, counted from from_bus to to_bus — see Signs and phase angles.

    Frequencies and the RMS row. frequency_Hz is Float64 in every frame of a solve. res_buses, res_branches and res_fault add one RMS row per element that combines all frequencies as \(\sqrt{\sum_f |X(f)|^2}\); that row has is_rms true and frequency_Hz null, and its angles, ratios and impedances are null, because they have no RMS. res_all_impedances and the decomposition frame have no RMS row. The exception are the comparison frames of an outage study: there frequency_Hz is text — "50.0", or "RMS" for the RMS row — because it is the key the scenarios are joined on. Filter with pl.col("is_rms") in the frames of a solve and with pl.col("frequency_Hz") == "RMS" in a comparison frame.

    Two reduction factors. reduction_factor (in res_fault: r_epr) is the EPR ratio with and without the inductive coupling — a property of the line, blind to the electrodes, and not the reduction factor of EN 50522. reduction_factor_current (in res_fault: r_current) is |I_E| / |I_F|, the reduction factor r of EN 50522. They coincide only for ideally bonded stations; see Which reduction factor is which.

    Missing values. A quantity the result marks as undefined is null, never a number: the current-based factor at a frequency without fault current, the earthing impedance of a fault bus without an electrode in its earthing group (diagnostic EARTHING_IMPEDANCE_UNDEFINED, see Warnings and diagnostics). The schemas are pinned, so an empty result is an empty frame with these columns, which can still be selected and filtered.

    import polars as pl
import groundinsight as gi

station = gi.BusType(name="station", system_type="Station", voltage_level=20.0,
                     impedance_formula="2.0")
cable = gi.BranchType(name="cable", grounding_conductor=True,
                      self_impedance_formula="(0.2 + j*2*pi*f*1.2e-3)*l",
                      mutual_impedance_formula="(j*2*pi*f*1.0e-3)*l")
net = gi.create_network(name="tables", frequencies=[50.0, 250.0])
for name in ("UW", "S1", "S2"):
    gi.create_bus(name=name, type=station, network=net)
gi.create_branch(name="K1", type=cable, from_bus="UW", to_bus="S1", length=1.0, network=net)
gi.create_branch(name="K2", type=cable, from_bus="S1", to_bus="S2", length=1.0, network=net)
gi.create_source(name="infeed", bus="UW", values={50.0: 1000.0, 250.0: 50.0}, network=net)
gi.create_fault(name="F", bus="S2", network=net)
gi.run_fault(net, "F")

buses = net.res_buses(fault="F")
at_50_hz = buses.filter(pl.col("frequency_Hz") == 50.0)    # one row per bus
rms = buses.filter(pl.col("is_rms"))                       # one row per bus, frequency_Hz null
print(buses.shape, at_50_hz.shape, rms["frequency_Hz"].null_count())   # (9, 10) (3, 10) 3

study = gi.run_outage_study(net, fault="F", scenarios=[gi.Outage(name="K2 out", disabled_branches=["K2"])])
compared = study.compare_buses()
print(compared.schema["frequency_Hz"])                     # String
print(compared.filter(pl.col("frequency_Hz") == "RMS").height)   # 6: 3 buses x 2 scenarios

    Results of a solve¶

    Network.res_buses(fault=None)¶

    One row per bus and frequency plus one RMS row per bus, for one fault or for every stored result. I_bus_A is the current through the bus's own electrode into the soil; I_inj_A is the current of the earthing conductor at a source or fault bus. Sizing an earthing conductor with I_bus_A underestimates it — the thermal check of the node uses the right one for each element.

    Column Type Unit Meaning
    bus_name String – name of the bus
    fault String – name of the fault the result belongs to
    frequency_Hz Float64 Hz frequency of the row; null on the RMS row
    is_rms Boolean – true on the one RMS row per element, which combines all frequencies as √Σ|X(f)|²
    EPR_V Float64 V earth potential rise of the bus, ResultBus.uepr_freq; RMS row: ResultBus.uepr
    EPR_degree Float64 ° angle of the EPR in the earth-side sign frame (see Conventions); null on the RMS row
    I_bus_A Float64 A electrode current: what the bus's own electrode passes into the soil, ResultBus.ia_freq; summed over all buses it is zero
    I_bus_degree Float64 ° angle of I_bus_A; null on the RMS row
    I_inj_A Float64 A current of the earthing conductor at a source or fault bus, ResultBus.i_inj_freq -- the source current at a source bus, the fault current at the fault bus, 0 elsewhere; the quantity a conductor is sized for
    I_inj_degree Float64 ° angle of I_inj_A; null on the RMS row

    Network.res_branches(fault=None)¶

    One row per branch and frequency plus one RMS row per branch.

    Column Type Unit Meaning
    branch_name String – name of the branch
    fault String – name of the fault the result belongs to
    frequency_Hz Float64 Hz frequency of the row; null on the RMS row
    is_rms Boolean – true on the one RMS row per element, which combines all frequencies as √Σ|X(f)|²
    I_branch_A Float64 A current of the earthing conductor (cable screen, earth wire) of the branch, ResultBranch.i_s_freq; counted positive from from_bus to to_bus for the physical fault
    I_branch_degree Float64 ° angle of I_branch_A; null on the RMS row

    Network.res_all_impedances()¶

    One row per stored fault and frequency, no RMS row: the earthing impedance and both reduction factors at the fault location.

    Column Type Unit Meaning
    fault_name String – name of the fault (this frame says fault_name, the others fault)
    fault_bus String – bus the fault sits on
    frequency_Hz Float64 Hz frequency of the row; the frame has no RMS row
    grounding_impedance_Ohm Float64 Ω earthing impedance Z_E of EN 50522 at the fault bus: the driving-point impedance of the earthing network seen from there (ResultGroundingImpedance.value, equal to z_earthing); null where it is undefined
    grounding_impedance_deg Float64 ° angle of Z_E
    reduction_factor Float64 – value: EPR at the fault bus with the inductive coupling over the EPR without it -- a property of the line, not the r of EN 50522
    reduction_factor_current Float64 – value_current: |I_E| / |I_F|, the reduction factor r of EN 50522

    Network.res_fault(fault)¶

    The key figures of one fault, read from the stored result: one row per network frequency plus one RMS row. The schema is gi.RES_FAULT_SCHEMA; this is the frame the EN 50522 how-to and the command line report.

    Column Type Unit Meaning
    fault String – name of the fault
    fault_bus String – bus the result was computed for
    frequency_Hz Float64 Hz frequency of the row; null on the RMS row
    is_rms Boolean – true on the one RMS row per element, which combines all frequencies as √Σ|X(f)|²
    I_F_A Float64 A fault current I_F (3I_0 of EN 50522): the currents of the sources that reach the fault, times the fault scalings (ResultReductionFactor.i_fault); RMS row √Σ|I_F(f)|²
    I_F_degree Float64 ° angle of I_F; null on the RMS row
    EPR_fault_V Float64 V earth potential rise of the fault bus; RMS row: its stored RMS value
    EPR_fault_degree Float64 ° angle of that EPR; null on the RMS row
    EPR_max_V Float64 V largest earth potential rise of any bus at that frequency (RMS row: largest RMS value)
    EPR_max_bus String – the bus where EPR_max_V occurs
    r_epr Float64 – EPR-based reduction factor value -- not the r of EN 50522; null on the RMS row
    r_current Float64 – current-based reduction factor value_current = |I_E| / |I_F|, the r of EN 50522; null on the RMS row and where it is undefined
    I_E_A Float64 A earth-return current I_E (i_earth); RMS row √Σ|I_E(f)|²
    U_E_V Float64 V earthing voltage U_E of EN 50522: the EPR at the fault bus (u_earthing); RMS row √Σ|U_E(f)|², the value compared with U_Tp
    Z_E_Ohm Float64 Ω earthing impedance Z_E of EN 50522, the driving point of the earthing network at the fault bus (z_earthing); null on the RMS row
    Z_E_degree Float64 ° angle of Z_E; null on the RMS row
    n_diagnostics Int64 – number of records in Result.diagnostics, the same on every row

    Studies¶

    SweepResult.buses(), .branches(), .impedances(), .cuts()¶

    A parameter sweep stacks the frames of its points: buses() the rows of res_buses, branches() those of res_branches (collected only with run_sweep(..., collect_branches=True)), impedances() those of res_all_impedances for the swept fault, and cuts() those of CutAnalysis.to_polars() (only with cuts=). Each frame starts with the column point (String, the SweepPoint.label) followed by one column per key of SweepPoint.parameters — rho_f_points adds bus, rho_Ohm_m and k1 … k5 — and then the columns of the frame it stacks, with the types listed above. A frame with nothing collected is an empty frame without columns. See Parameter sweeps and statistics.

    OutageStudyResult.compare_buses() and .compare_branches()¶

    Long format, one row per element, frequency, scenario and metric, with the difference to a reference scenario (against=, by default the base case). frequency_Hz is text here (see above).

    Column Type Unit Meaning
    bus_name String – name of the bus
    frequency_Hz String – frequency as text ("50.0") or "RMS" -- the join key of the comparison, not a number
    metric String – the compared res_buses column, EPR_V unless columns= names others
    value Float64 unit of the metric the metric in this scenario
    scenario String – scenario label (base for the unmodified network)
    delta_vs_base Float64 unit of the metric value minus the reference scenario's value; the suffix is the reference label (against=)
    delta_pct_vs_base Float64 % 100 · delta / reference value; null where the reference value is 0
    Column Type Unit Meaning
    branch_name String – name of the branch
    frequency_Hz String – frequency as text ("50.0") or "RMS"
    metric String – the compared res_branches column, I_branch_A unless columns= names others
    value Float64 unit of the metric the metric in this scenario
    scenario String – scenario label
    delta_vs_base Float64 unit of the metric value minus the reference scenario's value
    delta_pct_vs_base Float64 % 100 · delta / reference value; null where the reference value is 0

    CutAnalysis.to_polars()¶

    One row per direction (cut) and frequency of gi.analyze_cuts.

    Column Type Unit Meaning
    fault String – the analysed fault
    fault_bus String – bus the fault sits on, the reference point of the decomposition
    cut String – name of the direction (a Cut, or the implicit rest / source_loop side)
    side_buses String – buses seen through that cut, comma-separated
    n_side_buses Int64 – number of buses on that side
    branches String – branches of the cut, comma-separated
    sides_are_disjoint Boolean – true when no two directions reach the same bus; the far-side currents are defined only then
    frequency_Hz Float64 Hz frequency of the row (no RMS row)
    Z_side_Ohm Float64 Ω parallel impedance of that direction, from source-free current division
    Z_side_deg Float64 ° its angle
    Z_local_Ohm Float64 Ω impedance of the fault bus's own electrode
    Z_parallel_Ohm Float64 Ω Z_local in parallel with every Z_side
    Z_driving_point_Ohm Float64 Ω driving-point impedance of the solved nodal system at the fault bus
    identity_residual Float64 – |Z_parallel − Z_driving_point| / |Z_driving_point|; grows when the decomposition misses a current path
    I_fault_A Float64 A injection at the fault bus
    I_local_A Float64 A part of it taken by the fault bus's own electrode
    I_shield_A Float64 A shield current leaving the fault bus in that direction
    I_shield_deg Float64 ° its angle
    current_share Float64 – |I_shield| / |I_fault|
    I_earth_A Float64 A soil current crossing the cut, summed over the far side; null when the directions overlap
    I_total_A Float64 A total current crossing the cut; null when the directions overlap
    r_side Float64 – |I_earth| / |I_total|, the earth-return share of that direction
    kcl_residual Float64 – |I_fault − I_local − Σ I_shield| / |I_fault|; zero confirms the split accounts for the whole fault current

    select_rho_f_from_catalog(...)¶

    One row per catalogue entry, sorted by sort_by; one epr_<bus>_V column per swept fault bus.

    Column Type Unit Meaning
    name String – name of the catalogue entry
    k1 Float64 Ω/(Ω·m) coefficient of ρ in Z = k1·ρ + (k2 + j·k3)·f + (k4 + j·k5)·ρ·f
    k2 Float64 Ω/Hz coefficient of f, real part
    k3 Float64 Ω/Hz coefficient of f, imaginary part
    k4 Float64 Ω/(Ω·m·Hz) coefficient of ρ·f, real part
    k5 Float64 Ω/(Ω·m·Hz) coefficient of ρ·f, imaginary part
    max_epr_rms_V Float64 V largest RMS EPR over the swept fault buses
    admissible Boolean – max_epr_rms_V ≤ u_limit
    epr_<bus>_V Float64 V RMS EPR with the fault at that bus, one column per entry of bus_names

    summarize(frame, value, by=...) and classify(frame, value, edges)¶

    summarize returns one row per group: the grouping columns, then n, n_null, n_nan, mean, std, min, one column per quantile (p05, p50, p95 by default) and max — read n_nan first, a NaN propagates into the mean and the quantiles. classify returns its input with one String column added (class unless name= says otherwise); a null or NaN value gets a null class.

    ResultTransient.to_polars()¶

    Long format, one row per sample and signal.

    Column Type Unit Meaning
    time_s Float64 s time of the sample
    signal_kind String – epr for a bus potential, i_branch for a branch current, source for a source waveform
    name String – the observed bus, branch or source
    value Float64 V or A instantaneous value (not RMS), in the earth-side frame of the stationary results

    run_reference_cases()¶

    One row per closed-form reference case; see Verification and validation.

    Column Type Unit Meaning
    case String – name of the reference case
    quantity String – the compared quantity, with its unit
    conditions String – conditions under which the closed form holds
    closed_form Float64 unit of the quantity value of the closed form
    model Float64 unit of the quantity value the solver computes
    rel_deviation Float64 – |model − closed form| / |closed form|
    tolerance Float64 – largest admitted relative deviation
    agrees Boolean – rel_deviation ≤ tolerance

    Thermal checks¶

    check_conductor_limits(network, fault, ...)¶

    One row per branch. The thermal columns are null for a branch whose type declares no material and cross-section; the currents are filled in anyway. See Thermal limits of earthing conductors.

    Column Type Unit Meaning
    branch_name String – name of the branch
    I_s_rms_A Float64 A RMS of the earthing-conductor current over all frequencies, 0 Hz included
    I_dc_A Float64 A the 0 Hz component, taken out of the adiabatic check (THERMAL_DC_EXCLUDED)
    I_ac_rms_A Float64 A RMS of the alternating components, the I_k of the check
    i_p_A Float64 A peak current κ·√2·I_ac_rms, input for an electrodynamic check
    kappa Float64 – peak factor κ of IEC 60909-0
    m Float64 – DC heat factor m of IEC 60909-0
    n Float64 – AC heat factor n of IEC 60909-0
    t_k_s Float64 s short-circuit duration T_k
    I_th_factor Float64 – √(m + n), the factor from I_ac_rms to I_th
    I_th_A Float64 A thermal equivalent short-time current I_ac_rms·√(m + n)
    material String – conductor material of the branch type, null when not declared
    cross_section_mm2 Float64 mm² cross-section of the branch type, null when not declared
    k Float64 A·√s/mm² material constant k of IEC 60949 for the initial and final temperatures
    I_admissible_A Float64 A admissible short-time current k·S/√t_k
    utilization Float64 – I_th / I_admissible
    within_limit Boolean – utilization ≤ 1; null when the branch type declares no thermal data

    check_node_limits(network, fault, ...)¶

    One row per bus and element — earthing conductor and electrode.

    Column Type Unit Meaning
    bus_name String – name of the bus
    element String – earthing_conductor (carries I_inj) or electrode (carries I_bus)
    I_rms_A Float64 A RMS of the element's current over all frequencies, before the split
    current_split Float64 – share of that current one physical conductor carries (*_current_split of the bus type)
    I_conductor_A Float64 A I_rms · current_split
    I_dc_A Float64 A the 0 Hz component, taken out of the adiabatic check
    I_ac_rms_A Float64 A RMS of the alternating components
    i_p_A Float64 A peak current κ·√2·I_ac_rms
    kappa Float64 – peak factor κ
    m Float64 – DC heat factor m
    n Float64 – AC heat factor n
    t_k_s Float64 s short-circuit duration T_k
    I_th_factor Float64 – √(m + n), the factor from I_ac_rms to I_th
    I_th_A Float64 A thermal equivalent short-time current
    material String – material declared for the element, null when not declared
    cross_section_mm2 Float64 mm² cross-section declared for the element
    k Float64 A·√s/mm² material constant k of IEC 60949
    I_admissible_A Float64 A admissible short-time current k·S/√t_k
    utilization Float64 – I_th / I_admissible
    within_limit Boolean – utilization ≤ 1; null when the element is not declared

    Importers¶

    preview_pandapower_import(net, ...)¶

    One row per pandapower element that the import would keep or skip.

    Column Type Unit Meaning
    kind String – bus, line, switch, trafo or impedance
    status String – keep or skip
    pp_index Int64 – row index in the pandapower table
    name String – name the element gets (or had)
    vn_kv Float64 kV nominal voltage of a bus, null for the other kinds
    from_bus String – first bus of a line or bond
    to_bus String – second bus of a line or bond
    length_km Float64 km length the branch gets
    in_service Boolean – pandapower's in_service, becomes active
    reason String – why a row is skipped, see the reason table on the I/O page

    read_shortcircuit_results(net, ...)¶

    One row per bus of a case solved by pandapower.shortcircuit.calc_sc, in amperes.

    Column Type Unit Meaning
    pp_bus_index Int64 – pandapower bus index
    bus_name String – bus name, the key to the groundinsight network
    vn_kv Float64 kV nominal voltage
    fault_type String – fault type of the solved case, e.g. 1ph
    case String – max or min
    i_k_a Float64 A initial short-circuit current I_k'' (pandapower's ikss_ka in A)
    r1_ohm Float64 Ω positive-sequence resistance at the bus
    x1_ohm Float64 Ω positive-sequence reactance
    r0_ohm Float64 Ω zero-sequence resistance (earth faults)
    x0_ohm Float64 Ω zero-sequence reactance
    r_to_x Float64 – R/X of the fault loop; for 1ph the earth-fault loop (2R1 + R0)/(2X1 + X0)
    kappa Float64 – peak factor κ
    kappa_origin String – pandapower, iec_closed_form or unavailable
    t_k_s Float64 s short-circuit duration of the case
    n_factor Float64 – AC heat factor n
    m Float64 – DC heat factor m
    i_p_a Float64 A peak short-circuit current
    i_th_a Float64 A thermal equivalent short-time current

    apply_shortcircuit_characteristics(...)¶

    The audit trail: one row per source that feeds the fault.

    Column Type Unit Meaning
    fault_name String – the fault the characteristics were written for
    source_name String – a source that feeds it
    bus String – the source's bus
    frequency Float64 Hz frequency whose source value is meant
    i_k_total_a Float64 A I_k'' at the fault bus
    share Float64 – this source's share of it
    i_k_previous_a Float64 A the source value before the call
    i_k_a Float64 A the source's share of I_k''
    r_to_x Float64 – loop R/X written onto the source
    kappa Float64 – κ written onto the source
    kappa_origin String – where κ came from
    t_k_s Float64 s short-circuit duration written onto the fault
    n_factor Float64 – AC heat factor written onto the fault
    values_updated Boolean – whether Source.values was overwritten (set_source_values=True)
