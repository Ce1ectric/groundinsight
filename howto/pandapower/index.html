    Import from pandapower (topology and short circuit)¶

    A distribution network that already exists in pandapower does not have to be typed again. This guide imports its topology, reads a short-circuit case solved by pandapower and writes the IEC 60909 characteristics of the earth fault onto the grounding model. Two scripts, pandapower_topology.py and pandapower_shortcircuit.py; their outputs follow each part.

    The importer needs the optional extra:

    pip install "groundinsight[pandapower]"

    What pandapower provides — and what it does not¶

    pandapower describes the electrical network: buses, lines with their positive- and zero-sequence data, transformers, switches. It does not describe the earthing network: the electrodes of the stations, the screens of the cables and their coupling to the phase conductor. The import therefore takes the topology from pandapower — which buses exist, which lines join them, how long they are, what is in service — and the earthing side from the types you pass in gi.ImportDefaults: default_bus_type for every bus, default_branch_type for every line. Write those types from data sheets (how-to); the ones below are illustrative.

    Import the topology¶

    net_pp = pn.example_simple()

station = gi.BusType(name="MV station", system_type="Station", voltage_level=20.0,
                     impedance_formula="2*rho/(3*1.13*sqrt(100.0))")
cable_system = gi.BranchType(
    name="3x NA2XS(F)2Y 1x300RM/25 12/20 kV, trefoil",
    grounding_conductor=True,
    self_impedance_formula=(
        "(0.727/3 + pi**2*1e-4*f + j*4*pi*1e-4*f*log(658*sqrt(rho/f)/0.03151272))*l"
    ),
    mutual_impedance_formula=(
        "(pi**2*1e-4*f + j*4*pi*1e-4*f*log(658*sqrt(rho/f)/0.03151272))*l"
    ),
)
bond = gi.BranchType(name="busbar bond", grounding_conductor=True,
                     self_impedance_formula="(0.05 + j*2*pi*f*1e-3)*l",
                     mutual_impedance_formula="0")
defaults = gi.ImportDefaults(
    rho=100.0,
    frequencies=[50.0],
    default_bus_type=station,
    default_branch_type=cable_system,
    switch_branch_type=bond,          # closed bus-to-bus switches become 1 m branches
    derive_phase_impedance=True,      # phase_impedance_formula from r/x of each line
)

    gi.preview_pandapower_import(net_pp, voltage_level_kV=..., defaults=...) lists every element with keep or skip and the reason, before anything is built; gi.from_pandapower(...) builds the network. Pass the same defaults to both, so the preview shows the switches the way they will be imported.

    preview = gi.preview_pandapower_import(net_pp, voltage_level_kV=20.0, defaults=defaults)
counts = preview.group_by("status", "kind").len().sort("status", "kind")

    with collecting() as records:
    net = gi.from_pandapower(net_pp, defaults=defaults, voltage_level_kV=20.0,
                             network_name="example_simple, 20 kV")

    What decides the result:

    • Voltage level. A bus is imported when its vn_kv equals voltage_level_kV within a relative tolerance of 1e-9 — math.isclose(vn_kv, voltage_level_kV, rel_tol=1e-9) — so rounding noise from a CSV export does not drop the whole level. A line is imported when both ends are. A bus without a usable vn_kv is skipped (IMPORT_BUS_SKIPPED); if nothing is left, IMPORT_EMPTY says so — usually a wrong voltage_level_kV. A default bus type written for another level is announced (IMPORT_VOLTAGE_LEVEL_MISMATCH).
    • Closed bus-to-bus switches bond earthing systems. A closed switch between two buses (et="b") is imported as a short branch of ImportDefaults.switch_branch_type (length switch_length_km, 1 m by default). Without switch_branch_type it is left out — and a bus reached only through it is isolated and reads 0 V, the answer a grounding study must never get by accident. The import says so (IMPORT_SWITCH_NOT_IMPORTED); the preview calls it no_switch_branch_type. An open bus-to-bus switch is no connection (switch_open).
    • An open line switch opens the phase conductor, not the screen. A switch at a line end (et="l") is the switching state of that line. Open, it interrupts the phase conductor at that end; the screen is bonded to the station earth independently of the switch and stays connected at both stations — pandapower carries nothing that would say otherwise. The import gives such a line default_branch_type with phase_impedance_formula = "nan" (type <name>_phase_open): it carries no fault current, and its screen stays in the earthing network. It names line and switch (IMPORT_LINE_SWITCH_OPEN, severity info); the preview marks the switch and its line line_switch_open, a closed line switch line_switch_closed (it changes nothing). A ring operated open at a line switch therefore arrives open — see below. If the screen is interrupted as well, set the branch inactive. The legacy phase_current_mode="paths" enumerates routes over every active branch and does not see an open phase conductor; the default mode does.
    • Transformers and impedance elements are not modelled; they are listed in the preview and announced (IMPORT_ELEMENT_NOT_IMPORTED). A switch at a transformer terminal changes nothing (switch_not_bus_to_bus).
    • in_service becomes active, so an element out of service is out of the solve as well.
    • Lengths come from length_km; a line without a usable length gets 1 km (IMPORT_LENGTH_DEFAULT), a self-loop or a length that cannot be a branch is skipped (IMPORT_LINE_SKIPPED).

    The whole skip vocabulary is on the I/O page.

    with collecting() as records_without:
    isolated = gi.from_pandapower(
        net_pp, voltage_level_kV=20.0,
        defaults=defaults.model_copy(update={"switch_branch_type": None}))

    The phase-conductor impedance¶

    The default phase-current mode solves the phase-conductor network of rings and meshes, and needs a phase_impedance_formula on every branch of a mesh (otherwise the split uses a proxy, PHASE_PROXY). derive_phase_impedance — ImportDefaults(derive_phase_impedance=True) — writes one per line from pandapower's r_ohm_per_km and x_ohm_per_km: (r + I*x)*l. Two approximations come with it:

    • It is the positive-sequence impedance R₁ + jX₁ of the line. The phase network wants the reduced impedance Z_red \(= Z_{pp} - Z_m^2/Z_s\) of the phase conductor with the screen's return (data-sheet how-to). The split of the current over parallel routes depends only on the ratios of their impedances, so the approximation is exact only when all routes are of the same construction — the same ratio \(Z_\text{red}/(R_1 + jX_1)\) on every line. Mixed cable and overhead-line rings need their phase formulas written by hand.
    • The reactance is pandapower's value at the network frequency, used at every frequency. For harmonic studies write the formula with j*2*pi*f*L instead; at 0 Hz the constant reactance is dropped with a DC_LIMIT warning.

    The earth-return formulas are never derived: they depend on the soil and the cable geometry, which pandapower does not carry.

    A ring operated open¶

    example_simple has a ring MV Main Bus – MV Bus 1 – MV Bus 2 whose Line 3 is open at its switch at MV Bus 2. The import opens the phase conductor of Line 3, so a fault at MV Bus 2 is fed over Line 4 alone; the same net with every switch closed shows the ring that is not operated:

    gi.create_source(name="infeed", bus="MV Transformer Bus", values={50.0: 1000.0}, network=net)
gi.create_fault(name="F", bus="MV Bus 2", network=net)
gi.run_fault(net, "F")
phase_currents_open = dict(net.electrical_network.phase_currents[50.0])

# For comparison: the same pandapower net with every switch closed.
net_pp_closed = copy.deepcopy(net_pp)
net_pp_closed.switch["closed"] = True
ring = gi.from_pandapower(net_pp_closed, defaults=defaults, voltage_level_kV=20.0)
gi.create_source(name="infeed", bus="MV Transformer Bus", values={50.0: 1000.0}, network=ring)
gi.create_fault(name="F", bus="MV Bus 2", network=ring)
gi.run_fault(ring, "F")
phase_currents_closed = dict(ring.electrical_network.phase_currents[50.0])
line_3 = ring.branches["Line 3"].type

    With one cable type on every line the switch state moves the phase and screen currents — what the thermal check reads — but not the EPR: every coupling EMF is \(k\,I_p\) with the same \(k = Z_m/Z_s\), which amounts to injecting \((1-k)\,I_F\) however the phase current divides. In a ring of mixed construction the EPR moves as well.

    The 110 kV buses, the 110 kV line and the transformer are skipped; the 20 kV level is imported with all four buses connected. Without switch_branch_type the MV Transformer Bus would stand alone.

    Read a short-circuit case¶

    A limit check needs more of the fault current than its RMS value: the peak \(i_p\) and the thermal equivalent current \(I_{th}\) depend on the R/X of the fault loop and on the clearing time — quantities of the phase-side short-circuit calculation, which pandapower does. For an earth fault (fault="1ph") pandapower.shortcircuit.calc_sc needs, at minimum:

    Element Columns
    external grid s_sc_max_mva, rx_max, x0x_max, r0x0_max (the _min ones for case="min")
    lines r_ohm_per_km, x_ohm_per_km, c_nf_per_km and the zero sequence r0_ohm_per_km, x0_ohm_per_km, c0_nf_per_km (endtemp_degree for case="min")
    transformers, if any the zero-sequence data vk0_percent, vkr0_percent, mag0_percent, mag0_rx, si0_hv_partial and vector_group 
    net_pp = pp.create_empty_network(f_hz=50.0)
names = ["UW", "S1", "S2", "S3"]
index = {name: pp.create_bus(net_pp, vn_kv=20.0, name=name) for name in names}
pp.create_ext_grid(net_pp, index["UW"],
                   s_sc_max_mva=300.0,   # short-circuit power of the infeed
                   rx_max=0.1,           # R/X, positive sequence
                   x0x_max=1.0,          # X0/X1
                   r0x0_max=11.0)        # R0/X0 -- low-resistance earthing
for i, (a, b) in enumerate(zip(names[:-1], names[1:], strict=True), start=1):
    pp.create_line_from_parameters(
        net_pp, index[a], index[b], length_km=1.2, name=f"K{i}",
        r_ohm_per_km=0.100, x_ohm_per_km=0.110, c_nf_per_km=400.0, max_i_ka=0.5,
        r0_ohm_per_km=0.400, x0_ohm_per_km=0.350, c0_nf_per_km=400.0)
sc.calc_sc(net_pp, fault="1ph", case="max", ip=True, ith=True, tk_s=0.5)

    gi.read_shortcircuit_results(net_pp) turns net_pp.res_bus_sc into a frame in amperes with one row per bus; the fault type, case and clearing time come from the solved net. Two deliberate deviations from pandapower:

    • For fault="1ph" pandapower leaves ip_ka and ith_ka empty. The import computes \(\kappa = 1.02 + 0.98\,e^{-3R/X}\) on the earth-fault loop, \(R/X = (2R_1 + R_0)/(2X_1 + X_0)\), and from it \(i_p = \kappa\sqrt{2}\,I_k''\) and \(I_{th} = I_k''\sqrt{m + n}\); kappa_origin says iec_closed_form. Where pandapower does publish ip_ka, its value is used (pandapower).
    • \(I_{th}\) is always recomputed: pandapower sets the DC heat factor \(m\) to zero for \(\kappa > 1.99\), where its limit is 2 — too small an \(I_{th}\), in the unsafe direction.

    A bus without the data for κ is announced (SC_KAPPA_MISSING), a κ outside (1, 2] implied by pandapower's own numbers as well (SC_KAPPA_OUT_OF_RANGE).

    sc_results = gi.read_shortcircuit_results(net_pp)  # amperes, one row per bus

    Write the characteristics onto the model¶

    gi.apply_shortcircuit_characteristics(network, net_pp, fault) takes the row of the fault bus — matched by bus name, so the groundinsight network may be imported or built by hand — and writes R/X, κ and the share of \(I_k''\) onto every source that feeds the fault, and the clearing time t_k_s and the AC heat factor n_factor onto the fault. set_source_values=True also replaces the source currents by those shares; it is off by default, so a hand-tuned excitation is not replaced silently. The returned frame is the audit trail: i_k_previous_a next to i_k_a. A replaced t_k_s or n_factor of the fault is announced (SC_VALUE_REPLACED), an equal split between sources that inject nothing (SC_SPLIT_EQUAL), several matching rows (SC_ROW_AMBIGUOUS) and a voltage source that keeps its values (SC_VOLTAGE_SOURCE_SKIPPED). The thermal check then uses these characteristics (Thermal limits of earthing conductors).

    cable_system = gi.BranchType(
    name="3x NA2XS(F)2Y 1x300RM/25 12/20 kV, trefoil",
    grounding_conductor=True,
    self_impedance_formula=(
        "(0.727/3 + pi**2*1e-4*f + j*4*pi*1e-4*f*log(658*sqrt(rho/f)/0.03151272))*l"
    ),
    mutual_impedance_formula=(
        "(pi**2*1e-4*f + j*4*pi*1e-4*f*log(658*sqrt(rho/f)/0.03151272))*l"
    ),
    conductor_material="Cu", cross_section_mm2=69.7,  # three 25 mm2 screens, see the data-sheet how-to
    theta_final_C=gi.final_temperature("Cu", "XLPE"),
)
station = gi.BusType(name="station", system_type="Station", voltage_level=20.0,
                     impedance_formula="2*rho/(3*1.13*sqrt(100.0))")
defaults = gi.ImportDefaults(rho=100.0, frequencies=[50.0], default_bus_type=station,
                             default_branch_type=cable_system)
net = gi.from_pandapower(net_pp, defaults=defaults, voltage_level_kV=20.0)
gi.create_source(name="infeed", bus="UW", values={50.0: 1000.0}, network=net)
gi.create_fault(name="F", bus="S2", network=net)

with collecting() as records:
    report = gi.apply_shortcircuit_characteristics(net, net_pp, "F", set_source_values=True)
gi.run_fault(net, "F")
limits = gi.check_conductor_limits(net, "F")

    Check it by hand. pandapower reports for S2 \(R_1 = 0.386\ \Omega\), \(X_1 = 1.723\ \Omega\), \(R_0 = 17.043\ \Omega\) and \(X_0 = 2.175\ \Omega\), so \(R/X = (2 \cdot 0.386 + 17.043)/(2 \cdot 1.723 + 2.175) = 3.169\) and \(\kappa = 1.02 + 0.98\,e^{-9.51} = 1.0201\) — the low-resistance earthing makes the loop almost resistive. \(i_p = 1.0201 \cdot \sqrt 2 \cdot 2039.8 = 2942.6\) A. The test suite recomputes every row from pandapower's raw results this way.
