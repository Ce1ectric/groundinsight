    Harmonics, fault scalings and DC¶

    This guide sets up a fault study with several frequencies — the fundamental, harmonics, direct current — and shows what the solver does when the input covers only part of them. It uses one script, harmonics.py; its output is at the end of the page.

    Frequencies and source values¶

    Network.frequencies lists the frequencies the network is solved at, in Hz, as floats; 0.0 is DC. Every bus and branch evaluates its impedance formulas at each of them, and each frequency is an independent solve of the same nodal system. Keep the list strictly increasing — a shuffled list is kept but announced (FREQUENCY_ORDER), because the FFT transient solver maps bins by position.

    Source.values holds the RMS phasor of the source current per frequency, in A: the fundamental and the harmonic content of the earth-fault current at the infeed, from a measurement or a harmonic study. A peak value from a waveform record has to be divided by √2 first (Conventions).

    The example: a substation UW (0.5 Ω) feeds an earth fault at station S (ring electrode, 5.90 Ω at ρ = 100 Ω·m) over 3 km of the cable system of the data-sheet how-to, with 1000 A at 50 Hz, 60 A at 250 Hz and 40 A at 350 Hz (illustrative values):

    cable_system = gi.BranchType(
    name="3x NA2XS(F)2Y 1x300RM/25 12/20 kV, trefoil",
    grounding_conductor=True,
    self_impedance_formula=(
        "(0.727/3 + pi**2*1e-4*f + j*4*pi*1e-4*f*log(658*sqrt(rho/f)/0.03151272))*l"
    ),
    mutual_impedance_formula=(
        "(pi**2*1e-4*f + j*4*pi*1e-4*f*log(658*sqrt(rho/f)/0.03151272))*l"
    ),
)
substation = gi.BusType(name="substation", system_type="Substation", voltage_level=20.0,
                        impedance_formula="0.5")
station = gi.BusType(name="station", system_type="Station", voltage_level=20.0,
                     impedance_formula="2*rho/(3*1.13*sqrt(100.0))")  # ring electrode

FREQUENCIES = [50.0, 250.0, 350.0]
SOURCE_VALUES = {50.0: 1000.0, 250.0: 60.0, 350.0: 40.0}  # A, RMS per frequency
LENGTH_KM = 3.0

net = gi.create_network(name="harmonics", frequencies=FREQUENCIES)
gi.create_bus(name="UW", type=substation, specific_earth_resistance=100.0, network=net)
gi.create_bus(name="S", type=station, specific_earth_resistance=100.0, network=net)
gi.create_branch(name="K", type=cable_system, from_bus="UW", to_bus="S", length=LENGTH_KM,
                 specific_earth_resistance=100.0, network=net)
gi.create_source(name="infeed", bus="UW", values=SOURCE_VALUES, network=net)
gi.create_fault(name="F", bus="S", scalings={50.0: 1.0, 250.0: 1.0, 350.0: 1.0}, network=net)

    Fault scalings¶

    Fault.scalings multiplies the current of every source that reaches the fault, per frequency. The source values describe the infeed; the scalings describe the fault — which share of each frequency this fault draws. The rules:

    • scalings left out, None or {} means 1.0 at every frequency, without a warning.
    • A frequency missing from a non-empty mapping is scaled with 1.0 (full contribution), and the run announces it once (SCALINGS_INCOMPLETE). Write every frequency to make the choice explicit.
    • 0.0 excludes a frequency from this fault: {50.0: 1.0, 250.0: 0.0} solves the fault at 50 Hz alone, whatever the source carries at 250 Hz.
    • Fault.scaling_at(frequency) returns the factor the solve uses.
    gi.run_fault(net, "F")
figures = net.res_fault("F")  # one row per frequency and one RMS row

    net.faults["F"].scalings = {50.0: 1.0, 250.0: 0.0, 350.0: 0.0}  # this fault: 50 Hz only
gi.run_fault(net, "F")
u_e_rms_fundamental_only = net.res_fault("F").filter("is_rms")["U_E_V"][0]

    Per-frequency and RMS results¶

    res_fault, res_buses and res_branches have one row per frequency and one RMS row per element, which combines the frequencies as \(\sqrt{\sum_f |X(f)|^2}\) — the 0 Hz term with its full magnitude. The RMS row has is_rms true and frequency_Hz null, and its ratios, impedances and angles are null: a reduction factor has no RMS. Select a frequency with pl.col("frequency_Hz") == 250.0 and the RMS row with pl.col("is_rms"). res_all_impedances has no RMS row; the comparison frames of an outage study write frequency_Hz as text. All columns: Result tables.

    For the comparison with the permissible touch voltage of EN 50522, use the total RMS of U_E against the 50 Hz curve. That is conservative for the body current, not shown for the touch voltage; see Compare results with EN 50522 limits.

    Check it by hand. For one line between two stations the earth current has a closed form: with the source at UW and the fault at S, \(I_E = I\,(Z_s - Z_m)/(Z_{UW} + Z_S + Z_s)\) and \(U_E = Z_S\,I_E\). At 50 Hz the cable gives \(Z_s - Z_m = 3 \cdot 0.727/3 = 0.727\ \Omega\) (the screens' resistance; the earth-return terms cancel) and \(Z_{UW} + Z_S + Z_s = 7.275 + 1.940j\ \Omega\), so \(I_E = 1000 \cdot 0.727 / 7.529 = 96.56\) A, \(r = 0.0966\) and \(U_E = 5.900 \cdot 96.56 = 569.67\) V — the first row of the output. The test suite recomputes every row this way.

    When the input does not cover every frequency¶

    Input What the solve does Announced as
    a non-empty scalings without some network frequencies scales those with 1.0 SCALINGS_INCOMPLETE (InputWarning), once per run
    a source that reaches the fault, without a value at some network frequencies the source contributes 0 A there SOURCE_FREQUENCY_GAP (InputWarning), once per source and run
    a source that reaches the fault, without a value at any network frequency refuses: it would contribute 0 A everywhere ValueError naming the source, its keys and the network frequencies
    a source value at a frequency the network does not solve ignores the value SOURCE_FREQUENCY_OUTSIDE_NETWORK (InputWarning), when the source is created

    The first two arrive in Result.diagnostics; the last one is raised by create_source before any solve, so collect it with groundinsight.diagnostics.collecting(). gi.check_network(net) reports all three before a solve. Every code: Warnings and diagnostics.

    net.faults["F"].scalings = {50.0: 1.0, 250.0: 1.0}  # 350 Hz missing: scaled with 1.0
missing_scaling = gi.run_fault(net, "F")

net.faults["F"].scalings = None  # 1.0 at every frequency, no warning
net.sources["infeed"].values = {50.0: 1000.0, 250.0: 60.0}  # 350 Hz missing: 0 A there
missing_value = gi.run_fault(net, "F")

net.sources["infeed"].values = {16.7: 1000.0}  # no network frequency at all
try:
    gi.run_fault(net, "F")
except ValueError as refused:
    no_value = str(refused).split(". ")[0]

with collecting() as outside:  # announced when the source is created
    gi.create_source(name="extra", bus="UW", values={50.0: 10.0, 150.0: 5.0}, network=net)

    Direct current (f = 0)¶

    A DC study is an ordinary solve at f = 0; only the input needs care.

    • Network: frequencies=[0.0], or a mixed list such as [0.0, 50.0] — the 0 Hz bin is independent, and a study with both returns the same 50 Hz answer as one with 50 Hz alone.
    • Current source: a real value at 0.0, e.g. values={0.0: 1000.0}.
    • Voltage source: voltage and source_impedance with a 0.0 entry; the source impedance needs a real part, a purely inductive one is zero at DC.
    • Fault: no 0.0 key needed (1.0 by default); 0.0: 0.0 keeps DC out of a fault. The IEC 60909 characteristics (i_k_a, r_to_x, kappa) describe an alternating current and have no meaning in a DC study.

    How a formula is read at 0 Hz. The value is the limit for \(f \to 0\), found by approaching on 1e-6, 1e-7, 1e-8 Hz:

    • a reactance written as j*2*pi*f*L vanishes, and the Carson earth-return terms of a cable tend to their limit (zero for the mutual impedance) — nothing to announce;
    • a constant reactance such as + j*0.2 has no reading at DC: the 0 Hz bin keeps the real part and drops the reactance, with a DC_LIMIT warning (DCLimitWarning) when the element is created;
    • a pole — a series capacitance \(1/(j\omega C)\) — is an open circuit;
    • an exact zero — a purely inductive bond — is an ideal short circuit, which the nodal system cannot invert. The element gets a stand-in of \(\sqrt{\varepsilon_\text{mach}}\,Z_\text{min} = 1.49\cdot10^{-8}\,Z_\text{min}\), where \(Z_\text{min}\) is the smallest other impedance of the network at 0 Hz, and the run says so (DC_LIMIT in Result.diagnostics). Only the 0 Hz bin is affected.
    dc = gi.create_network(name="dc_chain", frequencies=[0.0])
for name, z in (("A", "0.8"), ("B", "12.0"), ("C", "3.5")):
    gi.create_bus(name=name, network=dc, type=gi.BusType(
        name=f"electrode {name}", system_type="Station", voltage_level=20.0, impedance_formula=z))
bond = gi.BranchType(name="bond", grounding_conductor=True,  # purely inductive: 0 at DC
                     self_impedance_formula="j*2*pi*f*1e-6*l", mutual_impedance_formula="0")
conductor = gi.BranchType(name="conductor", grounding_conductor=True,
                          self_impedance_formula="0.35*l", mutual_impedance_formula="0")
gi.create_branch(name="AB", type=bond, from_bus="A", to_bus="B", length=1.0, network=dc)
gi.create_branch(name="BC", type=conductor, from_bus="B", to_bus="C", length=1.0, network=dc)
gi.create_source(name="injection", bus="A", values={0.0: 1000.0}, network=dc)  # DC, real
gi.create_fault(name="F", bus="C", network=dc)
dc_result = gi.run_fault(dc, "F")
dc_potentials = {bus.name: bus.uepr_freq[0.0].real for bus in dc_result.buses}
stand_in = next(d for d in dc_result.diagnostics if d.code == "DC_LIMIT")
dc_substitute_ohm = float(stand_in.message.split("modelled with ")[1].split(" Ohm")[0])

    Check it by hand. In the chain above (electrodes 0.8 Ω, 12 Ω and 3.5 Ω, bond A–B purely inductive, 0.35 Ω from B to C, 1000 A injected at A, fault at C) the stand-in is \(1.49\cdot10^{-8} \cdot 0.35\ \Omega = 5.2\cdot10^{-9}\ \Omega\). The exact answer merges A and B into one node with \(0.8 \parallel 12 = 0.75\ \Omega\): \(u_{AB}\,(1/0.75 + 1/0.35) - u_C/0.35 = 1000\) and \(u_C\,(1/3.5 + 1/0.35) - u_{AB}/0.35 = -1000\) (the package's earth-side frame) give \(u_A = u_B = 57.07\) V and \(u_C = -266.30\) V — what the solve reports. Prefer the merge when the potential difference across an ideal bond is part of what you report, or give the bond a small honest resistance, which also removes the warning.

    What is refused. An impedance that is inverted — an electrode, a conductor with grounding_conductor=True, a source impedance — may not have a negative real part, nor a real part of \(-\infty\) at 0 Hz (a log(f) term without a factor f), nor be NaN; above 0 Hz it may not be zero either. Each raises a ValueError that names the element, the frequency and the formula. +inf (the formula "nan") stays legal everywhere: it is the open end.

    with collecting() as constant_reactance:  # '+ j*0.2' does not vanish at DC
    gi.create_branch(name="CA", network=dc, from_bus="C", to_bus="A", length=1.0,
                     type=gi.BranchType(name="fixed X", grounding_conductor=True,
                                        self_impedance_formula="0.35*l + j*0.2",
                                        mutual_impedance_formula="0"))
try:  # log(f) runs to minus infinity at DC: refused for an electrode
    gi.create_bus(name="D", network=dc, type=gi.BusType(
        name="log", system_type="Station", voltage_level=20.0, impedance_formula="1 + log(f)"))
except ValueError as refused:
    log_refused = str(refused).split(". ")[1]

    The reasoning behind these rules — the three kinds of singularity at 0 Hz, the measured accuracy of the stand-in — is in the explanation of direct current; the formula side is summarised in Formula syntax. Every transient study contains a 0 Hz bin as well: Transient simulation.
