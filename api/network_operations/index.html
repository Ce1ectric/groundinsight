    Network operations¶

    High-level factory functions to build a Network and run fault calculations. These are the functions re-exported on the top-level package as groundinsight.create_network, groundinsight.run_fault, etc.

    Physical / modelling context¶

    A Network is a graph: each Bus represents a grounding node with an own electrode impedance \(Z_B(f, \rho)\) (not the earthing impedance \(Z_E\) of EN 50522, which run_fault computes at the fault bus), every Branch a metallic return path with self-impedance \(Z_\text{branch}(f, l)\) and an optional mutual coupling that appears as a Norton injection along the source-to-fault path. Building the network and triggering a fault therefore requires four ingredients:

    1. Types — BusType, BranchType carrying SymPy formula strings in the free symbols rho, f and (for branches) l.
    2. Instances — Bus, Branch with concrete values for specific_earth_resistance, length, parallel_coefficient.
    3. Excitation — at least one Source (current or voltage) and one Fault declaring which bus is the ground-fault location and which fault scaling per frequency applies.
    4. Frequency list — the harmonics or per-fault spectrum at which the formula-based impedances are evaluated.

    run_fault then assembles the nodal admittance matrix, runs the sparse LU solve per frequency, and stores the result on the Network (net.results).

    Example¶

    import groundinsight as gi

# 1. Frequency list and types
net = gi.create_network(name="demo", frequencies=[50.0, 250.0])
bus_type = gi.BusType(
    name="GroundRod",
    system_type="Substation",
    voltage_level=20.0,
    impedance_formula="rho/(2*3.14159*1.5)*(1 + j*0.01*f)",
)
branch_type = gi.BranchType(
    name="ShieldCable",
    grounding_conductor=True,
    self_impedance_formula="(0.2 + j*0.4*f/50)*l",
    mutual_impedance_formula="(0.0 + j*0.4*f/50)*l",
)

# 2. Instances
gi.create_bus(name="bus_substation", type=bus_type,
              specific_earth_resistance=100.0, network=net)
gi.create_bus(name="bus_fault", type=bus_type,
              specific_earth_resistance=100.0, network=net)
gi.create_branch(name="line_1", type=branch_type,
                 from_bus="bus_substation", to_bus="bus_fault",
                 length=2.0, network=net)

# 3. Source and fault
gi.create_source(name="src1", bus="bus_substation",
                 values={50.0: 1.0, 250.0: 0.05}, network=net)
gi.create_fault(name="f1", bus="bus_fault",
                scalings={50.0: 1.0, 250.0: 0.05}, network=net)

# 4. Run
gi.run_fault(network=net, fault="f1")
print(net.res_buses(fault="f1"))

    The same workflow scales to multi-source ring or mesh topologies. The default phase_current_mode="auto" splits the phase current of a meshed network by solving the phase-conductor network itself; give the branch types a phase_impedance_formula, otherwise the split uses proxy impedances and the result says so (PHASE_PROXY).

    A network without excitation is rejected¶

    Step 3 is not optional. A network without a source or without a fault has nothing that drives a current, and the calculation used to run to completion anyway and report 0 V at every bus. That is a plausible-looking answer, and the most common way to arrive at it is a forgotten gi.create_source(...), not a network that is genuinely unexcited. run_fault (and the path enumeration of Pathfinder) now raises a ValueError naming the missing side.

    A fault that no source reaches over active elements is a different matter and stays permitted: that is exactly what an outage scenario islanding the fault bus produces, and 0 V is then the correct answer. gi.check_network reports it (FAULT_NOT_REACHED).

    create_network_assistant and the n−1 rule¶

    A line of n buses has n − 1 branches, so branch_length needs n − 1 entries:

    net = gi.create_network_assistant(
    name="Line30", frequencies=[50.0, 250.0], number_buses=30,
    bus_type=bus_type, branch_type=branch_type,
    branch_length=[1.0] * 29,          # 29, not 30
    specific_earth_resistance=100.0,
)

    Passing n lengths used to drop the last one silently — the two tests in this repository that did so had been asserting against a shorter line than they thought for as long as they existed — and passing too few raised a bare IndexError from inside the loop. Both now raise a ValueError that states the two counts.

    API reference¶

    network_operations ¶

    Network Operations Module.

    This module provides functions for managing the electrical network, including creating networks, buses, branches, faults, and sources. It also includes functions to build the electrical network, define paths, and run fault calculations. These operations utilize the core models defined in groundinsight.models.core_models and interact with the Network instance to perform necessary calculations and updates.

    def create_branch(
    name: str,
    type: BranchType,
    from_bus: str,
    to_bus: str,
    length: float,
    specific_earth_resistance: Optional[float] = 100,
    description: Optional[str] = None,
    network: Optional[Network] = None,
    parallel_coefficient: Optional[float] = 1.0,
) -> Branch:
    """
    Create a new :class:`Branch` instance and optionally add it to a network.

    If a :class:`Network` instance is provided, the branch is added to the
    network, which also triggers the self- and mutual-impedance
    calculations against the network's frequency list.

    Parameters
    ----------
    name : str
        The name of the branch.
    type : BranchType
        The type of the branch.
    from_bus : str
        The name of the originating bus.
    to_bus : str
        The name of the terminating bus.
    length : float
        The length of the branch in km; finite and strictly positive.
    specific_earth_resistance : float, optional
        The specific earth resistance for the branch (Ohm * m). Defaults
        to ``100``.
    description : str, optional
        A brief description of the branch. Defaults to ``None``.
    network : Network, optional
        The network to which the branch should be added. Defaults to
        ``None``.
    parallel_coefficient : float, optional
        Per-branch share of the source-to-fault phase current; used by
        the path-based mutual-coupling injection. Defaults to ``1.0``.
        **Only read in the legacy phase-current mode**
        ``run_fault(..., phase_current_mode="paths")``. The default mode
        ``"auto"`` solves a reduced phase-conductor network from
        ``BranchType.phase_impedance_formula``, where the split follows from
        the phase impedances and this value is ignored.

    Returns
    -------
    Branch
        A newly created :class:`Branch` instance.

    Raises
    ------
    ValueError
        If the specified ``from_bus`` or ``to_bus`` does not exist in the
        provided network, if ``length`` is not a finite positive number of
        km, or if the impedances cannot be derived from ``type``. The
        network is unchanged in every case.

    Examples
    --------
    >>> import groundinsight as gi
    >>> branch_type = gi.BranchType(
    ...     name="StandardBranch", grounding_conductor=True,
    ...     self_impedance_formula="(1 + j * f / 50)*l",
    ...     mutual_impedance_formula="(0.5 + j * f / 100)*l",
    ... )
    >>> branch = gi.create_branch(
    ...     name="Branch1", type=branch_type,
    ...     from_bus="Bus1", to_bus="Bus2", length=1.0,
    ... )
    >>> branch.name
    'Branch1'
    """
    # Validate buses if network is provided
    if network:
        if from_bus not in network.buses:
            raise ValueError(
                f"from_bus '{from_bus}' is not in the network '{network.name}'"
            )
        if to_bus not in network.buses:
            raise ValueError(
                f"to_bus '{to_bus}' is not in the network '{network.name}'"
            )

    branch = Branch(
        name=name,
        type=type,
        length=length,
        from_bus=from_bus,
        to_bus=to_bus,
        specific_earth_resistance=specific_earth_resistance,
        self_impedance={},  # Will be calculated
        mutual_impedance={},  # Will be calculated
        description=description,
        parallel_coefficient=parallel_coefficient,
    )
    if network:
        network.add_branch(branch)
        # Impedance calculations are triggered within network.add_branch()
    return branch

    """

    def create_fault(
    name: str,
    bus: str,
    scalings: Optional[Dict] = None,
    active: bool = False,
    description: Optional[str] = None,
    network: Optional[Network] = None,
    t_k_s: Optional[float] = None,
    n_factor: float = 1.0,
) -> Fault:
    """
    Create a new :class:`Fault` instance and optionally add it to a network.

    If a :class:`Network` instance is provided, the fault is added to the
    network. If ``active=True``, the fault becomes the currently active
    fault in the network.

    Parameters
    ----------
    name : str
        The name of the fault.
    bus : str
        The name of the bus where the fault occurs.
    scalings : dict of float to float, optional
        Factor applied to the source currents, per frequency. ``None`` (the
        default) or ``{}`` means 1.0 at every frequency. A frequency missing
        from a non-empty mapping is scaled with 1.0 as well -- full
        contribution, not zero -- and ``run_fault`` announces the incomplete
        mapping once per run (``InputWarning`` ``SCALINGS_INCOMPLETE``). Give
        ``0.0`` to exclude a frequency from this fault.
    active : bool, optional
        Whether to activate the fault immediately upon creation. Defaults
        to ``False``.
    description : str, optional
        A brief description of the fault. Defaults to ``None``.
    network : Network, optional
        The network to which the fault should be added. Defaults to
        ``None``.
    t_k_s : float, optional
        IEC 60909-0 short-circuit duration ``T_k`` in seconds. When set,
        :func:`groundinsight.check_conductor_limits` can derive the
        thermal rating without an explicit ``t_k`` argument.
    n_factor : float, default 1.0
        IEC 60909-0 AC heat factor ``n``. Keep the default ``1.0`` for
        far-from-generator faults, which is the normal case in grounding
        studies.

    Returns
    -------
    Fault
        A newly created :class:`Fault` instance.

    Raises
    ------
    ValueError
        If the specified bus does not exist in the provided network, if
        ``t_k_s`` is not a positive duration, if ``n_factor`` lies
        outside ``(0, 1]``, or if ``active=True`` is passed without a
        network. The network is unchanged in every case.

    Examples
    --------
    >>> import groundinsight as gi
    >>> bus_type = gi.BusType(
    ...     name="StandardBus", system_type="Grounded", voltage_level=110,
    ...     impedance_formula="1 + j * f / 50",
    ... )
    >>> network = gi.create_network(name="TestNetwork", frequencies=[50, 60])
    >>> _ = gi.create_bus(name="Bus1", type=bus_type, network=network)
    >>> fault = gi.create_fault(
    ...     name="Fault1", bus="Bus1",
    ...     scalings={50: 1.0, 60: 0.8},
    ...     active=True, network=network,
    ... )
    >>> fault.name
    'Fault1'
    """
    if active and network is None:
        raise ValueError(
            f"create_fault(name='{name}', active=True) needs a network: a "
            "fault can only be the active one *in* a network. Pass "
            "network=..., or leave active=False and call "
            "network.set_active_fault(...) once the fault has been added."
        )
    if network and bus not in network.buses:
        raise ValueError(f"bus '{bus}' is not in the network '{network.name}'")

    fault = Fault(
        name=name,
        description=description,
        bus=bus,
        scalings=scalings,
        t_k_s=t_k_s,
        n_factor=n_factor,
    )

    if network:
        network.add_fault(fault)

    if active:
        network.set_active_fault(name)

    return fault

    def create_network_assistant(
    name: str,
    frequencies: List,
    number_buses: int,
    bus_type: BusType,
    branch_type: BranchType,
    branch_length: List,
    specific_earth_resistance: float,
    description: Optional[str] = None,
) -> Network:
    """
    Create a linear network with a uniform bus and branch type.

    Initialises a :class:`Network` instance and populates it with
    ``number_buses`` buses and ``number_buses - 1`` branches connected
    sequentially to form a line topology. Impedance calculations are
    triggered upon adding buses and branches to the network.

    Parameters
    ----------
    name : str
        The name of the network.
    frequencies : list of float
        Frequencies (in Hz) at which network calculations are performed.
    number_buses : int
        The total number of buses to create.
    bus_type : BusType
        The type to assign to each bus.
    branch_type : BranchType
        The type to assign to each branch.
    branch_length : list of float
        Lengths of each branch connecting the buses. Must have
        ``number_buses - 1`` elements.
    specific_earth_resistance : float
        The specific earth resistance for all buses and branches
        (Ohm * m).
    description : str, optional
        A brief description of the network. Defaults to ``None``.

    Returns
    -------
    Network
        A fully initialised :class:`Network` instance with the specified
        configuration.

    Raises
    ------
    ValueError
        If ``number_buses`` is not an integer ``>= 1``, or if the length
        of ``branch_length`` does not match ``number_buses - 1``.

    Notes
    -----
    A line of ``n`` buses has ``n - 1`` branches, so ``branch_length``
    has one entry *fewer* than ``number_buses``. Passing ``n`` lengths --
    ``[1.0] * 30`` for ``number_buses=30``, read as "a 30 km line" -- is
    refused rather than truncated: dropping the surplus entry would return a
    network one span shorter than the one asked for, with no warning
    anywhere. Too few entries are refused the same way instead of failing
    with a bare ``IndexError`` from inside the loop.

    Examples
    --------
    >>> import groundinsight as gi
    >>> station = gi.BusType(name="station", system_type="Substation",
    ...                      voltage_level=20.0, impedance_formula="rho * 0.01")
    >>> cable = gi.BranchType(name="cable", grounding_conductor=True,
    ...                       self_impedance_formula="(0.25 + j * f * 0.012) * l",
    ...                       mutual_impedance_formula="j * f * 0.012 * l")
    >>> net = gi.create_network_assistant(
    ...     name="Linear5", frequencies=[50.0], number_buses=5, bus_type=station,
    ...     branch_type=cable, branch_length=[1.0] * 4, specific_earth_resistance=100.0)
    >>> list(net.buses), list(net.branches)
    (['bus1', 'bus2', 'bus3', 'bus4', 'bus5'], ['branch1', 'branch2', 'branch3', 'branch4'])
    """
    if isinstance(number_buses, bool) or not isinstance(number_buses, int):
        raise ValueError(
            f"number_buses must be an int >= 1, got "
            f"{number_buses!r} ({type(number_buses).__name__})."
        )
    if number_buses < 1:
        raise ValueError(f"number_buses must be >= 1, got {number_buses}.")

    try:
        n_lengths = len(branch_length)
    except TypeError:
        raise ValueError(
            f"branch_length must be a sequence of {number_buses - 1} lengths "
            f"(one per branch), got {branch_length!r} "
            f"({type(branch_length).__name__})."
        ) from None
    if n_lengths != number_buses - 1:
        raise ValueError(
            f"branch_length has {n_lengths} entries but a line of "
            f"{number_buses} buses has {number_buses - 1} branches. "
            "A line of n buses needs n-1 lengths."
        )

    net = create_network(name, frequencies, description)

    for i in range(number_buses):
        # create a bus with the name "bus"+i+1
        bus_name = f"bus{i+1}"
        create_bus(bus_name, bus_type, specific_earth_resistance, network=net)
        if i > 0:
            # create a branch with the name "branch"+i which connectes the buses from idx i-1 and i
            branch_name = f"branch{i}"
            create_branch(
                branch_name,
                branch_type,
                f"bus{i}",
                bus_name,
                branch_length[i - 1],
                specific_earth_resistance,
                network=net,
            )

    return net

    bus: str,
    voltage: Dict,
    source_impedance: Dict,
    description: Optional[str] = None,
    network: Optional[Network] = None,
) -> Source:
    """
    Create a Thevenin (voltage) source and optionally add it to a network.

    The Thevenin source models a frequency-dependent EMF ``voltage`` in
    series with a finite ``source_impedance``. In contrast to
    :func:`create_source`, which creates an ideal current source for
    stationary studies, this factory is intended for transient analyses
    where the fault current is determined by the loop impedance
    ``Z_src + Z_loop`` rather than being prescribed.

    Parameters
    ----------
    name : str
        The name of the source.
    bus : str
        The name of the bus where the source is located.
    voltage : dict of float to ComplexNumber or complex
        Frequency-dependent EMF.
    source_impedance : dict of float to ComplexNumber or complex
        Frequency-dependent internal impedance. Must use the same
        frequency keys as ``voltage`` and must be non-zero.
    description : str, optional
        A brief description of the source. Defaults to ``None``.
    network : Network, optional
        The network to which the source should be added. Defaults to
        ``None``.

    Returns
    -------
    Source
        A newly created Thevenin source instance with
        ``source_type='voltage'``.

    Raises
    ------
    ValueError
        If the specified bus does not exist in the provided network, or
        if the input dictionaries do not satisfy the voltage-mode
        constraints.

    Examples
    --------
    >>> import groundinsight as gi
    >>> from groundinsight.api.examples import build_minimal
    >>> net = build_minimal()
    >>> source = gi.create_voltage_source(
    ...     name="grid", bus="bus1",
    ...     voltage={50: 11547.0}, source_impedance={50: 0.5 + 2.0j},
    ...     network=net,
    ... )
    >>> source.source_type, sorted(net.sources)
    ('voltage', ['grid', 'src'])
    """
    if network and bus not in network.buses:
        raise ValueError(f"bus '{bus}' is not in the network '{network.name}'")

    source = Source(
        name=name,
        description=description,
        bus=bus,
        source_type="voltage",
        voltage=voltage,
        source_impedance=source_impedance,
    )
    if network:
        network.add_source(source)
    return source

def run_fault(
    network: Network,
    fault: str,
    auto_parallel_coefficients: Optional[bool] = None,
    *,
    phase_current_mode: str = "auto",
):
    """
    Execute the fault calculation pipeline for a single fault.

    Sets the named fault as the active fault, builds the electrical
    network, solves the per-frequency nodal system, computes branch
    currents, reduction factors and grounding impedance. The results are
    stored on ``network.results[fault]``. :func:`groundinsight.solve` runs the
    same pipeline without writing anything into ``network``.

    Parameters
    ----------
    network : Network
        The network instance on which the fault calculations are to be
        performed.
    fault : str
        The name of the fault to activate and run calculations for. The
        former keyword ``fault_name`` is accepted as a deprecated alias.
    auto_parallel_coefficients : bool, optional
        Deprecated alias for ``phase_current_mode``. ``True`` maps to
        ``"auto"``, ``False`` to ``"paths"``. When given it wins over
        ``phase_current_mode`` so existing call sites keep their exact
        behaviour. Defaults to ``None`` (not given).
    phase_current_mode : {"auto", "paths"}, optional
        How the phase current per branch is determined.

        ``"auto"`` (default) solves a reduced phase-conductor network per
        source with the fault bus as reference and reads the branch
        currents off that solution. This is the only mode that splits the
        source current correctly over rings, meshes and parallel
        branches, and it ignores ``Branch.parallel_coefficient``.

        ``"paths"``: every branch on any enumerated source-to-fault path
        receives the *full* source current scaled by its
        ``parallel_coefficient``. In a meshed network that multiplies the
        current instead of splitting it: in a symmetric ring of two routes,
        at the default coefficient of 1.0, the coupled injections add up to
        ``(1 - 2k) I`` instead of ``(1 - k) I`` (``k = Z_m / Z_s``). That
        collapses the EPR to 0 for ``k = 0.5`` and, where ``|1 - 2k| = 1``,
        reports it as if the shields did not couple at all. Kept for
        reproducing studies made with this scheme and for networks where the
        split is known from measurement and set by hand.

    Returns
    -------
    Result
        The result of the run -- the same object that is stored as
        ``network.results[fault]``. Its ``diagnostics`` list holds every
        package warning raised during the run, with code and element
        references (see :mod:`groundinsight.diagnostics`).

    Raises
    ------
    ValueError
        If the specified fault does not exist in the network, if the
        network defines no sources or no faults at all, or if
        ``phase_current_mode`` is not one of the two accepted values.
    RuntimeError
        If there is an error during the network calculations.

    Warns
    -----
    ModelAssumptionWarning
        Among others (every package warning of the run is collected into
        ``Result.diagnostics``): ``PARALLEL_COEFFICIENT_DEFAULT`` when
        ``phase_current_mode="paths"`` meets a source that reaches the fault
        over several paths with default parallel coefficients, and
        ``EARTH_GROUP_SPREAD`` when the electrode currents are spread in angle
        so that ``I_E`` and ``value_current`` describe the dominant direction
        only.

    Notes
    -----
    ``"auto"`` does **not** enumerate the source-to-fault paths. It only
    needs to know which sources reach the fault, which
    :meth:`~groundinsight.models.core_models.Network.sources_reaching`
    answers with a breadth-first search over the active sub-graph. The
    enumeration is exponential in the number of independent loops -- a
    6x6 grid has 1 262 816 simple paths, about a minute of enumeration per
    ``run_fault`` while the solver itself needs milliseconds -- so it runs
    only in ``"paths"`` mode or when the user asks for it with
    :func:`create_paths`. ``network.paths`` is therefore normally empty
    after a default ``run_fault``; a path set that no longer matches the
    active topology is dropped so no later reader picks it up.

    Examples
    --------
    >>> import polars as pl
    >>> import groundinsight as gi
    >>> from groundinsight.api.examples import build_minimal
    >>> net = build_minimal()
    >>> result = gi.run_fault(net, "fault")
    >>> result is net.results["fault"]
    True
    >>> epr = net.res_buses("fault").filter(pl.col("is_rms"))
    >>> [(row["bus_name"], round(row["EPR_V"], 2)) for row in epr.iter_rows(named=True)]
    [('bus1', 18.03), ('bus2', 0.0), ('bus3', 18.03)]
    """
    auto_phase_currents = _resolve_phase_current_mode(
        phase_current_mode, auto_parallel_coefficients
    )

    # Set the active fault
    network.set_active_fault(fault)

    # (Re)build paths when they are missing or the active topology changed
    # since they were last built (e.g. a manual Bus.active / Branch.active
    # flip or an in-place rewiring). Without this check run_fault would
    # silently reuse stale paths while the Y-matrix is rebuilt from the
    # current active flags, yielding a wrong EPR.
    #
    # Only the legacy ``phase_current_mode="paths"`` actually needs the
    # enumerated paths -- there they carry the phase current per branch.
    # ``"auto"`` (the default) solves a reduced phase-conductor network and
    # only needs to know *which* sources reach the fault, which
    # ``Network.sources_reaching`` answers with a breadth-first search. The
    # enumeration is exponential in the number of loops (1.26 million paths
    # and roughly a minute on a 6x6 grid, against milliseconds in the
    # solver), so it is not triggered in the default mode. Stale
    # paths are still dropped so that no later reader -- persistence, the
    # transient state-space solver, the short-circuit aggregation -- picks
    # up a path set that no longer matches the topology. Users who want the
    # paths as data keep asking for them with ``gi.create_paths(network)``.
    _assert_network_is_excited(network)
    # Every package warning raised from here on belongs to this run. The
    # sink is per thread/task (see groundinsight.diagnostics), so concurrent
    # runs keep their messages apart, and it records warnings the caller has
    # filtered out as well -- the result carries them either way.
    with collecting() as sink:
        if not auto_phase_currents:
            if network.needs_path_rebuild():
                network.invalidate_paths()
                create_paths(network)
        elif network.paths and network.needs_path_rebuild():
            network.invalidate_paths()

        # Warn only in the legacy mode, and only when the network around this
        # fault actually has parallel routes -- see _warning_parallel_coeffcient.
        if not auto_phase_currents:
            _warning_parallel_coeffcient(network, auto_phase_currents)

        # Build the electrical network from the physical network.
        # auto_phase_currents switches the phase-current determination from
        # the path-based scheme (parallel_coefficient per branch) to the
        # phase-network solve.
        build_electrical_network(network, auto_phase_currents=auto_phase_currents)

        # Solve the network
        network.electrical_network.solve_network()

        # Compute branch currents
        network.electrical_network.compute_branch_currents()

        # Compute reduction factors
        network.electrical_network.compute_reduction_factors()

        # Compute grounding impedance
        network.electrical_network.compute_grounding_impedance()

    # Results are stored in net.results within the ElectricalNetwork methods;
    # the diagnostics of the run are attached to that same object.
    result = network.results[fault]
    result.diagnostics = unique(sink)
    # Stamp the inputs the result was computed from; Network.stale_results
    # compares the stamp with the network's inputs at any later time (GUI3).
    result.input_digest = network.input_digest(fault)
    return result
