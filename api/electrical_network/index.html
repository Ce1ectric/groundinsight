    Electrical network¶

    Numerical core of groundinsight. ElectricalNetwork assembles the nodal admittance matrix \(Y(f)\) per frequency, fills the right-hand side with source and mutual-coupling Norton currents, solves the linear system via sparse LU and derives branch currents, reduction factors and grounding impedances.

    Physical / modelling context¶

    For each frequency \(f\) in the network's frequency list the model reduces to a sparse complex linear system

    \[ Y(f)\,\underline{u}(f) \;=\; \underline{i}(f), \qquad \underline{u}(f) \;=\; Y(f)^{-1}\,\underline{i}(f), \]

    with

    • \(Y(f)\) the nodal admittance matrix. The diagonal holds the admittances of the bus electrodes, \(1/Z_B(f, \rho)\) (the symbol \(Z_E\) is reserved for the earthing impedance of EN 50522, see the glossary); the branch self-admittances \(1/Z_b(f, l)\) of the branches with grounding_conductor=True join the buses they connect.
    • \(\underline{u}(f)\) the bus-EPR vector.
    • \(\underline{i}(f)\) the source currents (scaled by the fault scaling at \(f\)) plus the Norton equivalents of the mutual coupling between phase and grounding conductor along the source-to-fault path.

    After the per-frequency solve the network derives:

    • Branch currents from \(\Delta u\) and the impressed mutual current.
    • Two reduction factors. value is the EPR ratio \(|\underline{u}_\text{with}|/|\underline{u}_\text{without}|\) at the fault bus, where the second solve omits the mutual Norton sources — a property of the line, not the reduction factor of EN 50522. value_current is \(|I_E|/|I_F|\), the earth-return current over the fault current: the reduction factor \(r\) of EN 50522. Both are stored in ResultReductionFactor (which one is which).
    • Earthing impedance \(Z_G = Z_E = Z_\text{dp}(F)\) per frequency (EN 50522): the driving-point impedance of the earthing network at the fault bus -- electrodes and shields, without the coupling and without Thevenin loop closures. The earthing voltage \(U_E\) is the EPR at the fault bus. The current-weighted mean of the earth group and its quotient by \(I_E\), reported as \(U_E\)/\(Z_E\) before audit pass 19, remain available as u_earthing_group / z_earthing_group.

    The ElectricalNetwork is held as a PrivateAttr of Network, not exposed in the JSON / DB serialisation; it carries the raw NumPy / SciPy working arrays used by the LU solver.

    Example¶

    # fragment: assumes a network `net` with the fault "f1"
import groundinsight as gi

# Assume `net` was built via gi.create_* factories with a fault `f1`.
gi.run_fault(network=net, fault="f1")  # attaches net.electrical_network

# Inspect derived quantities through the public Network accessors:
df_bus = net.res_buses()           # EPR per bus
df_branch = net.res_branches()     # branch currents
df_zg = net.res_all_impedances()   # grounding impedance + reduction factor

    Direct use of ElectricalNetwork is rarely needed; access is mostly via gi.run_fault and the Network.res_* DataFrame accessors.

    API reference¶

    electrical_network ¶

    The numerical kernel of the fault solve, built from the core models.

    :class:ElectricalNetwork computes with the matrix form of the network:

    Y * u = i u = Y^-1 * i

    where:

    Y - admittance matrix, branches and buses are used to build this matrix u - vector of bus voltages (earth potential rise per bus) i - vector of source injections plus the Norton-equivalent injections that represent the inductive coupling between phase conductors and shield (grounding) conductors along each branch.

    Sign convention for the mutual coupling (see _add_mutual_currents): U_from - U_to = Z_self * I_s - Z_mutual * I_p where I_p is the phase current through the branch in from->to direction and I_s is the shield current in the same direction. The induced EMF enters the nodal form as a Norton current i_mut = (Z_mutual / Z_self) * I_p which is injected as +i_mut out of the from bus (nodal: i_vector[from] -= i_mut) and +i_mut into the to bus (nodal: i_vector[to] += i_mut).

    Two strategies are available to determine the phase current I_p per branch: 1) Path-based (auto_phase_currents=False, the default of this class; run_fault(phase_current_mode="paths")). For every simple path from source to fault, the branch direction is derived from the actual path traversal (no index heuristic). The user may scale the contribution per branch via Branch.parallel_coefficient, the knob for splitting current between parallel paths in this mode. 2) Automatic distribution (auto_phase_currents=True; the default of :func:~groundinsight.run_fault, phase_current_mode="auto"). A reduced phase-only network is solved with +I at each source bus and the fault bus as reference. The resulting branch currents are used directly. In this mode parallel_coefficient is ignored. This mode is topology-agnostic and is the intended integration point for an external phase-current source (e.g. pandapower single-phase short-circuit results).

    Sparse kernel

    Both linear systems of a frequency are sparse -- a grounding network has a few entries per row -- and the kernel treats them that way end to end.

    Model values as arrays. The impedance dictionaries of all buses, branches and voltage sources are read once per assembly into (elements, F) arrays (:class:_NetworkTables), with the 0 Hz stand-in applied to them as a whole. Every later stage indexes into those arrays instead of resolving one impedance per element and frequency in Python.

    Index tables instead of dense matrices. Where a stamp lands -- a bus diagonal, the four entries of a grounding branch or of a Thevenin loop closure -- depends on the topology only. The positions are laid out once per network (:class:_StampPattern: CSC indices/indptr and the entry of every stamp); a frequency then costs one vector of admittances and one summation per entry, straight into the CSC matrix the LU factorises (:attr:ElectricalNetwork.Y_sparse). A dense n x n matrix kept per frequency would make the memory grow as n**2 * F; Y_matrices is therefore only a dense view that materialises a matrix when someone reads it.

    One factorisation, many right-hand sides. The phase-conductor network is the same matrix for every source, so it is factorised once per frequency (:func:scipy.sparse.linalg.splu) and solved for all sources as the columns of one right-hand side. A dense n x n solve per source and frequency would be the dominant cost of a run, growing faster than n**2.

    Result objects with the collector paused. A solve creates one :class:ComplexNumber per element, quantity and frequency. Those objects form no reference cycles, but their sheer number keeps triggering the cyclic garbage collector, which then walks the whole network model each time. The result rows are therefore built inside :func:_gc_paused, which restores the collector afterwards.

    Program order, kept on purpose. Matrices are assembled from stamps whose contributions are summed entry by entry in the order an element-by-element dense assembly adds them (:func:_assemble_csc), so the sums are those of that reference. What differs from it is rounding: the admittances come from NumPy's complex division, which differs from Python's in the last bit for about a quarter of all values, and the factorisation is a sparse LU instead of LAPACK's dense one. On the badly conditioned phase network of a long radial feeder the sparse LU is the more accurate of the two.

    		 False
    input_checks bool

    		 False
    Notes

    An instance is copied and pickled together with the :class:Network it is attached to (copy.deepcopy(network), network.model_copy(deep=True), pickle.dumps(network)). Every attribute travels with it except the entries named in :attr:_UNCOPYABLE_CACHES: those hold SciPy SuperLU factorisations, which can be neither pickled nor deep-copied. They are pure caches -- a copy starts without them and the solver refactorises when it needs a factor again -- so dropping them loses no information. The back-reference :attr:network is copied through the copy memo and therefore points at the copied network, which is what :meth:matches_network_state needs.

    def compute_branch_currents(self):
    """
    Compute branch currents for each frequency and store them in the Result object.

    This method calculates the current flowing through each branch based on the bus voltages
    and branch impedances. The results are stored as `ResultBranch` instances within the
    network's results object.
    """
    fault_name = self.network.active_fault
    if fault_name is None:
        raise ValueError("No active fault set in the network.")

    if fault_name not in self.network.results:
        raise ValueError(f"No results available for fault '{fault_name}'.")

    result = self.network.results[fault_name]
    tables = self._network_tables()
    frequencies = self.network.frequencies

    # Inactive branches and branches with at least one inactive endpoint
    # are open-circuited: their shield current is zero by construction, as
    # is that of a branch without grounding conductor and of a frequency
    # whose self impedance is missing or open. Everything else carries
    # (u_to - u_from) * Y_self plus the stored mutual term, whose sign
    # already combines with that difference (see _add_mutual_currents).
    conducting = (
        (tables.branch_in_net & tables.branch_grounding)[:, None]
        & tables.self_present
        & ~_open_mask(tables.self_z)
    )
    admittance = _reciprocal(tables.self_z, conducting)
    potentials = self._stacked(self.u_vectors)
    from_idx = np.where(tables.branch_from >= 0, tables.branch_from, 0)
    to_idx = np.where(tables.branch_to >= 0, tables.branch_to, 0)
    names = tables.branch_names
    mutual = np.zeros(admittance.shape, dtype=complex)
    for j, freq in enumerate(frequencies):
        stored = self.i_mutuals.get(freq, {})
        if stored:
            mutual[:, j] = np.fromiter(
                (stored.get(name, 0) for name in names), dtype=complex,
                count=len(names),
            )
    current = np.zeros(admittance.shape, dtype=complex)
    with np.errstate(over="ignore", invalid="ignore"):
        delta = potentials[to_idx] - potentials[from_idx]
        current[conducting] = (delta * admittance + mutual)[conducting]
    result.branches.extend(
        self._result_rows(ResultBranch, names, frequencies, {"i_s": current})
    )

    # Update the result in the network's results dictionary
    self.network.results[fault_name] = result
    self.results = result  # Update self.results

    compute_grounding_impedance()

    Compute the grounding impedance for the fault bus.

    The grounding impedance is the earthing impedance of EN 50522 at the fault bus::

    Z_G = Z_E = Z_dp(F)

    the driving-point impedance of the earthing network at the fault bus: the voltage one ampere injected there raises the bus to against remote earth, with every electrode and shield in place, without the inductive coupling and without the Thevenin loop closures of voltage sources. It is a property of the earthing system -- what an earthing-impedance measurement at the station sees, the stations bonded to it through cable shields included -- and it is computed alongside the reduction factors as ResultReductionFactor.z_earthing, which this method copies. With U_E the EPR at the fault bus and r = |1 - Z_m/Z_s| the norm's chain U_E = r * 3*I_0 * Z_E then holds where the norm's assumptions hold (a fault far from the infeed on a long bonded run), as a physical statement rather than by construction.

    The quotient U_E / I_E over the earth group is not used for Z_E (it is kept as z_earthing_group): on a long homogeneous chain it comes out 44.5 % below the driving-point impedance. docs/explanation/reduction-factors.md and docs/api/electrical_network.md state the same definition.

    The results are stored in the network's results object.

    The grounding impedance is the earthing impedance of EN 50522 at the
    fault bus::

        Z_G = Z_E = Z_dp(F)

    the driving-point impedance of the earthing network at the fault bus:
    the voltage one ampere injected there raises the bus to against remote
    earth, with every electrode and shield in place, without the inductive
    coupling and without the Thevenin loop closures of voltage sources. It
    is a property of the earthing system -- what an earthing-impedance
    measurement at the station sees, the stations bonded to it through
    cable shields included -- and it is computed alongside the reduction
    factors as ``ResultReductionFactor.z_earthing``, which this method
    copies. With ``U_E`` the EPR at the fault bus and
    ``r = |1 - Z_m/Z_s|`` the norm's chain ``U_E = r * 3*I_0 * Z_E`` then
    holds where the norm's assumptions hold (a fault far from the infeed
    on a long bonded run), as a physical statement rather than by
    construction.

    The quotient ``U_E / I_E`` over the earth group is not used for
    ``Z_E`` (it is kept as ``z_earthing_group``): on a long homogeneous
    chain it comes out 44.5 % below the driving-point impedance.
    ``docs/explanation/reduction-factors.md`` and
    ``docs/api/electrical_network.md`` state the same definition.

    The results are stored in the network's results object.
    """

    if fault_name is None:
        raise ValueError("No active fault set in the network.")

    fault_bus = self.network.faults[fault_name].bus

    grounding_impedances = (
        {}
    )  # Dictionary to store grounding impedance per frequency

    frequencies = self.network.frequencies

    result = self.network.results[fault_name]

    # Ensure that reduction factors are computed
    if not result.reduction_factor:
        raise ValueError(
            "Reduction factors not computed. Please compute reduction factors before grounding impedance."
        )

                real=complex(z_earthing).real, imag=complex(z_earthing).imag

        # (no bus connected to it through shields carries an electrode):
        # the earthing network alone presents no finite impedance there.
        grounding_impedances[freq] = None

    def compute_reduction_factors(self):
    """
    Compute the reduction factors by solving the network with and without mutual currents.

    This method calculates how much the presence of mutual currents affects the Earth Potential Rise (EPR).
    The reduction factors are stored in the network's results object.

    Warns
    -----
    ModelAssumptionWarning
        ``REDUCTION_FACTOR_UNDEFINED`` (elements: the fault and its bus)
        for a frequency at which the EPR-based reduction factor is
        undefined -- the no-mutual EPR of the fault bus is rounding noise,
        or the solve without mutual coupling failed there.

    Notes
    -----
    The no-mutual system uses the *same* ``Y(f)`` that
    :meth:`solve_network` has already factorised, only with a different
    right-hand side. The sparse LU factors kept in ``self._lu_factors``
    are therefore reused and the second solve costs one triangular
    back-substitution. The earlier ``numpy.linalg.solve`` refactorised
    the matrix densely -- 2.5 s of a 6.9 s profile on a 200-bus chain
    over 50 frequencies -- and did so with a *different* singularity
    treatment than the first solve, so the two paths could disagree
    about whether the same matrix was solvable. Frequencies without a
    stored factor (``compute_reduction_factors`` called on its own)
    factorise :attr:`Y_sparse` afresh with the same sparse LU.
    """
    fault_name = self.network.active_fault
    if fault_name is None:
        raise ValueError("No active fault set in the network.")

    fault_bus = self.network.faults[fault_name].bus
    fault_bus_idx = self.bus_indices[fault_bus]

    reduction_factors = {}
    uepr_with_mutual = {}
    uepr_without_mutual = {}

    frequencies = self.network.frequencies

    # Step 1: Solve network with mutual currents (already done)
    # Voltages are stored in self.u_vectors

    # Store uepr with mutual currents
    for freq in frequencies:
        voltage = self.u_vectors[freq][fault_bus_idx]
        uepr_with_mutual[freq] = voltage
    # Step 2: Create i_vectors without mutual currents
    self._construct_vectors_no_mutual()
    # Step 3: Solve network without mutual currents
    self.u_vectors_no_mutual = {}
    for freq in frequencies:
        i_vector = self.i_vectors_no_mutual[freq]
        lu = self._lu_factors.get(freq)
        try:
            # Solve for u_vector without mutual currents. The LU factors
            # of Y(f) come from ``solve_network``; only a caller that
            # skipped it has to pay for a fresh factorisation.
            if lu is None:
                lu = splu(self.Y_sparse[freq])
            u_vector = lu.solve(i_vector)
            self.u_vectors_no_mutual[freq] = u_vector

        except (np.linalg.LinAlgError, RuntimeError) as e:
            # Result-relevant: the EPR-based reduction factor of this
            # frequency is reported as None, and the reader has to know
            # why (GUI4). The traceback stays available at DEBUG level.
            logger.debug(
                "Solve without mutual currents failed at %s Hz.",
                freq,
                exc_info=True,
            )
            emit(
                ModelAssumptionWarning,
                f"Fault '{fault_name}': the solve without mutual coupling "
                f"failed at {freq:g} Hz ({type(e).__name__}: {e}), so the "
                f"EPR-based reduction factor (ResultReductionFactor.value) "
                f"is undefined there and reported as None. The solution "
                f"with coupling -- the EPR and every current -- is not "
                f"affected.",
                code="REDUCTION_FACTOR_UNDEFINED",
                elements=[("fault", fault_name), ("bus", fault_bus)],
                stacklevel=3,
            )
            continue

    # Store uepr without mutual currents. A frequency whose no-mutual solve
    # failed above is absent from ``u_vectors_no_mutual``; it is skipped here
    # and reported as ``None`` rather than raising a bare KeyError out of the
    # solver core.
    for freq in frequencies:
        if freq not in self.u_vectors_no_mutual:
            continue
        voltage = self.u_vectors_no_mutual[freq][fault_bus_idx]
        uepr_without_mutual[freq] = voltage

    # Z_E of EN 50522 (F4): the driving-point impedance of the earthing
    # network at the fault bus. Computed first, because it is also the
    # yardstick of the noise rule for the EPR-based factor below.
    z_driving_point, z_undefined = self._earthing_driving_points(fault_bus_idx)

    # Step 4: Compute reduction factors
    epr_undefined: List[Tuple[float, float, float]] = []
    for freq in frequencies:
        if freq not in uepr_without_mutual:
            reduction_factors[freq] = None
            continue
        v_with = uepr_with_mutual[freq]
        v_without = uepr_without_mutual[freq]
        # Compute magnitudes
        mag_with = abs(v_with)
        mag_without = abs(v_without)

        # The quotient means something only while its denominator stands
        # above rounding noise (P9). A fault bus that is at zero potential
        # in exact arithmetic -- every source on the fault bus, or a source
        # behind a dead end that returns all its current through one
        # shield -- comes out at ~1e-14 V, and the ratio of two such
        # numbers would be reported as a reduction factor (0.449 =
        # 5.1e-14 V / 1.1e-13 V for a source behind a dead end, next to
        # 320 V at the source tower). The yardstick is the EPR the fault
        # current would raise the fault bus to on its own,
        # |I_F| * |Z_FF|: an exact zero sits at ~1e-16 of it, while a
        # near-ideal fault-bus electrode -- a small but accurate EPR --
        # stays at the order of |1 - k| of it.
        # (The largest EPR of the solution is no yardstick: it calls the
        # near-ideal electrode noise.)
        i_fault = complex(self.total_source_currents.get(freq) or 0)
        reference = 0.0
        if i_fault != 0:
            z_ff = z_driving_point.get(freq)
            if z_ff is None:
                z_ff = self._solved_driving_point(freq, fault_bus_idx)
            reference = abs(i_fault) * (abs(z_ff) if z_ff is not None else 0.0)
        if mag_without > NOISE_REL * reference:
            reduction_factor = mag_with / mag_without
        else:
            reduction_factor = None
            # Said out loud only where the earthing network is excited at
            # all. Every source on the fault bus injects nothing anywhere:
            # that null case has no earth current and no factor by
            # definition, as it always had, and a study that scans every
            # bus as a fault location would otherwise repeat it per bus.
            if i_fault != 0 and self._is_excited(freq):
                epr_undefined.append((freq, mag_without, reference))
        reduction_factors[freq] = reduction_factor

    # Step 5: the current-based reduction factor -- see the method docstring.
    (
        reduction_factors_current,
        earth_currents,
        earth_buses,
        earthing_voltages,
        earthing_impedances,
        group_undefined,
    ) = self._compute_current_reduction_factors()

    self._report_undefined_reduction_quantities(
        fault_name, fault_bus, epr_undefined, group_undefined, z_undefined
    )

    # The two definitions answer different questions and only coincide in
    # the limit of ideally bonded stations. Saying so where they part
    # company beats leaving a factor of forty to be discovered later.
    self._warn_on_reduction_factor_divergence(
        reduction_factors, reduction_factors_current
    )

    # The EN 50522 quantities (F4): U_E is the EPR at the fault bus -- the
    # very number ResultBus reports there -- and Z_E the driving-point
    # impedance of the earthing network at the fault bus. The group mean
    # and its quotient by I_E, which carried these names before, stay
    # available as diagnostics.
    fault_currents = {
        freq: (
            None
            if self.total_source_currents.get(freq) is None
            else complex(self.total_source_currents[freq])
        )
        for freq in frequencies
    }
    fault_potentials = {
        freq: complex(self.u_vectors[freq][fault_bus_idx]) for freq in frequencies
    }

    # Store the reduction factors in the result
    result = self.network.results[fault_name]
    result_reduction_factor = ResultReductionFactor(
        fault_bus=fault_bus,
        value=reduction_factors,
        value_current=reduction_factors_current,
        i_fault=fault_currents,
        i_earth=earth_currents,
        earth_buses=earth_buses,
        u_earthing=fault_potentials,
        z_earthing=z_driving_point,
        u_earthing_group=earthing_voltages,
        z_earthing_group=earthing_impedances,
    )
    result.reduction_factor = result_reduction_factor

    # Update the result in the network's results dictionary
    self.network.results[fault_name] = result
    self.results = result  # Update self.results

        is not modified.

    def solve_network(self):
    """
    Solve the network equations Y * u = i for each frequency.

    This method computes the bus voltages by solving the admittance matrix equations for each frequency.
    The results are stored in the network's results object.
    It uses the csc_matrix and splu functions from scipy, assuming the Y-Matrix is a sparse matrix.

    .. warning::

        This **replaces** ``network.results[fault]`` with a fresh
        :class:`Result` that carries bus rows only. The branch rows are
        filled in by :meth:`compute_branch_currents`, which must be
        called afterwards -- :func:`groundinsight.run_fault` does exactly
        that. Calling ``solve_network`` on its own, e.g. on a hand-built
        :class:`ElectricalNetwork` used to inspect ``Y``, ``i`` or ``u``,
        therefore discards the branch results of a previous ``run_fault``.
        Clearing them is deliberate -- stale branch currents next to fresh
        bus voltages would be silently inconsistent -- and the thermal
        checks raise on the resulting gap rather than reporting an
        incomplete result as free of violations.

        To inspect the nodal system without touching the stored results,
        build the :class:`ElectricalNetwork` (its constructor has no side
        effects on ``network.results``) and read ``u`` back from
        ``network.results[fault].buses`` instead of re-solving.
    """
    fault_name = self.network.active_fault
    if fault_name is None:
        raise ValueError("No active fault set in the network.")

    result = Result(buses=[], branches=[], fault=fault_name)
    # Drop factorisations of a previous solve: the Y matrices may have
    # been rebuilt since (a changed rho, a flipped active flag), and a
    # stale factor would silently answer with the old topology.
    self._lu_factors = {}
    tables = self._network_tables()
    for freq in self.network.frequencies:
        Y_matrix = self.Y_sparse[freq]
        i_vector = self.i_vectors[freq]
        singular_msg = (
            f"Singular admittance matrix at f={freq} Hz: the network has no "
            "path to reference earth. Ensure at least one bus has a finite "
            "grounding impedance and that the fault bus is connected to it."
        )
        # A NaN anywhere in the nodal system poisons the factorisation, and
        # scipy reports that as a singular matrix -- which reads like a
        # topology error and sends the engineer looking for a missing
        # earth connection that is not missing. Catch it first and name
        # what is actually NaN.
        self._assert_finite_system(freq, Y_matrix, i_vector)

        # Exact, solver-independent floating-network guard. If no active bus
        # is referenced to earth at this frequency (every grounding impedance
        # is zero, infinite or missing) the admittance matrix is singular.
        # scipy's sparse ``splu`` handles a singular Y inconsistently across
        # versions -- it may raise ``RuntimeError``, return a non-finite
        # solution, or return an arbitrary finite one (a floating network has
        # no unique EPR) -- so the common floating case is caught structurally
        # here, before the solve, with no numerical tolerance. The test runs
        # on the stored values as a whole; the per-bus classification is
        # only needed for the message.
        stored = tables.bus_z_raw[:, tables.column[float(freq)]]
        present = tables.bus_present[:, tables.column[float(freq)]]
        if not np.any(present & np.isfinite(stored) & (stored != 0)):
            grouped = self._classify_bus_grounding(freq)
            raise ValueError(self._no_ground_reference_message(freq, grouped))
        # The same question for every group of buses the matrix couples:
        # one group without an electrode is enough to make Y singular, and
        # once it holds two or more buses only up to rounding -- splu then
        # returns 1e18 V for it instead of raising (see component_labels).
        floating = self._floating_buses(freq, Y_matrix)
        if floating:
            raise ValueError(self._floating_group_message(freq, floating))
        try:
            # Backstops for any remaining singular case (e.g. a disconnected
            # ungrounded island): scipy may raise, or return a non-finite
            # solution. The matrix is assembled as CSC, so it is factorised
            # as it is -- no dense-to-sparse scan.
            lu = splu(Y_matrix)
            u_vector = lu.solve(i_vector)
        except (np.linalg.LinAlgError, RuntimeError) as e:
            raise ValueError(f"{singular_msg} Original solver error: {e}") from e
        if not np.all(np.isfinite(u_vector)):
            raise ValueError(singular_msg)
        self.u_vectors[freq] = u_vector
        # Keep the factorisation: ``compute_reduction_factors`` solves the
        # *same* Y with a second right-hand side (the injection without the
        # mutual Norton terms). Re-using the factor turns that second solve
        # into a triangular back-substitution.
        self._lu_factors[freq] = lu

    # Create ResultBus instances. Inactive buses are not in ``bus_indices``
    # and therefore do not appear in the result -- they are physically
    # disconnected from the nodal system. The electrode current is
    # ``u / Z`` with the 0 Hz stand-in applied, zero for a missing or open
    # electrode; the injection is the source-only vector.
    frequencies = self.network.frequencies
    potentials = self._stacked(self.u_vectors)
    self._electrode_currents = None
    electrode, usable = self._electrode_arrays(potentials)
    injection = self._stacked(self.source_injections)
    result.buses.extend(
        self._result_rows(
            ResultBus,
            list(self.bus_indices),
            frequencies,
            {"uepr": potentials, "ia": electrode, "i_inj": injection},
        )
    )

    # Store the result in the network's results dictionary
    self.network.results[fault_name] = result
    self.results = result  # Also keep a reference in self.results

    -------

    def restricted_columns(
    matrix, rows: np.ndarray, units: List[int]
) -> Optional[np.ndarray]:
    """
    Unit-injection columns of ``matrix``, solved on one group of buses only.

    Internal API: also used by :mod:`groundinsight.analysis.response`; not
    exported from ``groundinsight`` and free to change in any release.

    The buses outside ``rows`` are decoupled from it by construction (see
    :func:`component_labels`), so the columns inside the group do not
    depend on them -- and a floating group elsewhere in the matrix cannot
    make this solve singular.

    Parameters
    ----------
    matrix : scipy.sparse.spmatrix
        Square nodal matrix.
    rows : numpy.ndarray
        Boolean mask of the group.
    units : list of int
        Rows (inside the group) at which one ampere is injected, one column
        each.

    Returns
    -------
    numpy.ndarray or None
        ``(n, len(units))`` voltages, zero outside the group; ``None`` if the
        group's matrix is numerically singular or the solve is not finite.
    """
    index = np.flatnonzero(rows)
    sub = csc_matrix(matrix.tocsr()[index][:, index])
    rhs = np.zeros((index.size, len(units)), dtype=complex)
    rhs[np.searchsorted(index, units), np.arange(len(units))] = 1.0
    try:
        solved = splu(sub).solve(rhs)
    except (np.linalg.LinAlgError, RuntimeError):
        return None
    if not np.all(np.isfinite(solved)):
        return None
    columns = np.zeros((matrix.shape[0], len(units)), dtype=complex)
    columns[index] = solved
    return columns

    """RMS over the frequency columns, the convention of the result rows.

    Internal API: also used by :mod:`groundinsight.analysis._session`; not
    exported from ``groundinsight`` and free to change in any release.

    ----------
    values : numpy.ndarray
        Complex array ``(elements, F)``.

    Returns
    -------
    numpy.ndarray
        Float array ``(elements,)``.
    """
    square = np.zeros(values.shape[0])
    for j in range(values.shape[1]):
        magnitude = np.abs(values[:, j])
        square += magnitude * magnitude
    return np.sqrt(square)
